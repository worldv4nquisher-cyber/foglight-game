# v0.1-012 光线反射系统（光源、镜子、接收器、光路可视化）

- **负责人**：程序
- **里程碑**：M5
- **依赖**：004
- **工时估算**：3–4 人日

## 背景
GDD §7 谜题 3、5，§8 机制库「旋转反射镜」「光感锁 / 点火口」「间歇自然光」，§9（镜子 15° 档、精调 7.5°、光感锁 1.5 s、点火口 1.0 s 进入可点灯 + 断光容差 0.3 s、最大反射 4 次、云缝光 40 s 周期 / 25 s 持续）。美术约束（GDD §12、style-guide §0）：谜题 3 光束为风灯暖色；谜题 5 光路在点火前保持**冷白**，点火瞬间才转暖。

## 具体内容
1. **光源 `BeamEmitter`**：位置 + 方向（取 GLB 中 `-emitter` 空节点的 +Z），颜色参数（`warm` / `coldWhite`），开关状态。类型：
   - `socket`：风灯放到带聚光罩的灯台 socket 上时开启（谜题 3）。
   - `sky`：云缝天光，按周期开关（40 s 一周期、亮 25 s，参数可配），可由事件切为常亮（谜题 5 开油阀后）。开关时 1 s 淡入淡出。
2. **光路计算**：从光源发射射线，命中 `Mirror`（GLB 中 `-mirror-plane` 节点，+Z 为镜面法线；只有正面反射，背面挡光）按反射定律折返；命中其他带碰撞体的物体则停止并在命中点生成光斑；最多 4 次反射。只在光源/镜子/门等状态变化时重算（事件驱动），不是每帧全量重算。
3. **镜子 `Mirror`**：挂在 004 的 `RotatablePart` 上（单轴或双轴），旋转时实时重算光路。
4. **接收器 `BeamReceiver`**：GLB 中 `-receiver` 节点 + 半径（默认 0.3 m）。光路命中半径内持续 N 秒触发。两种模式：`auto`（光感锁，1.5 s 后发 `receiver:activated`，保持原行为）；`manual`（点火口，用户 2026-10-29 确认：受光不再自动点燃，连续受光 1.0 s 后发 `receiver:ready` 进入可点灯状态，断光超过容差后发 `receiver:lost`，由 015 的点灯交互决定何时点燃）。断光容差 `graceSec` 可配（点火口 0.3 s，光感锁默认 0）：断开不超过容差时进度不归零、状态不退出；可配置「前置条件」（点火口要求油阀已开，未满足时只发红光并发 `receiver:blocked`，谜题 5「没有油。」）。命中期间输出 0–1 进度给材质（锁上透镜逐渐变亮）。
5. **可视化（白盒版）**：每段光束用发光圆柱/带状网格 + 末端光斑，颜色按光源；接收器命中时脉动。正式的体积光束在 024 替换，接口保持 `BeamRenderer` 可替换。
6. 调试：开发模式 `?beamDebug=1` 画出射线与法线。

## 验收标准
- [ ] 测试场景：光源 → 镜 A → 镜 B → 接收器，转动镜子时光路实时更新，无闪烁。
- [ ] 入射角 30° 时反射角 30°（`verify-beam.mjs` 断言误差 < 0.1°）。
- [ ] 第 5 次反射不再计算；光打到镜子背面被挡住。
- [ ] `auto` 模式：光路持续命中接收器 1.5 s 后触发 `receiver:activated`；中途移开则进度归零。
- [ ] `manual` 模式（点火口）：连续命中 1.0 s 发 `receiver:ready`；断开 ≤ 0.3 s 不归零也不退出；断开 > 0.3 s 发 `receiver:lost`、进度归零；`manual` 模式从不自己发 `receiver:activated`。
- [ ] 点火口前置条件未满足时命中只发红光，并发出 `receiver:blocked`，不计进度、不发 `receiver:ready`；条件满足后从那一刻重新计 1.0 s。
- [ ] 天光光源按 40 s / 25 s 周期开关；收到事件后常亮。
- [ ] 光源颜色可切换（暖 / 冷白），用于谜题 5 点火瞬间转暖。
- [ ] 3 面镜子 + 4 次反射的场景下，光路重算单次 ≤ 1 ms。
