# v0.1-006 存档与设置存储

- **负责人**：程序
- **里程碑**：M4
- **依赖**：无（可与 001 并行）
- **工时估算**：1.5–2 人日

## 背景
GDD §11（存档规则全文）、§10（设置项）。现有 `QualityManager` 已把画质档位记在本地，需要并入统一的设置存储。

## 具体内容
1. **存档**（localStorage 键 `foglight.save.v1`，单存档位）：
   - 结构：`{ version: 1, chapterId, sceneId, readDocs: string[], playTimeSec, hintsUsed, chapterComplete: boolean, savedAt }`。
   - 自动存档时机：开场演出结束进入 S1、每次进入新场景（场景切换黑场中）、点亮灯塔进入章节结束页。无手动存档。
   - 读档：「继续」进入存档场景入口，场景内谜题全部为初始状态（GDD §11，不做谜题级存档）。
   - 章节完成后「继续」进入章节结束页。
   - 异常：版本号不匹配或 JSON 解析失败 → 返回 `null` 并让主菜单提示「存档无法读取」，只提供新游戏；localStorage 不可写（隐私模式）→ 主菜单提示「进度不会保存」，游戏照常运行。
2. **设置**（键 `foglight.settings.v1`，新游戏不清除）：画质档位（`ultra|high|standard`，默认 `ultra`，见 009）、是否已完成画质检测、鼠标灵敏度（0.1–3.0，默认 1.0）、Y 轴反转、主音量/音乐/音效（0–100）、字幕大小（`s|m|l`，默认 `m`）、自动回正（默认关）、显示帧率（默认关）。把 `QualityManager` 现有的本地存储迁移到这里，并兼容读取旧键一次后删除旧键。
3. 游玩时间每 10 秒累加一次到内存，存档时写入。

## 交付物
- `game/src/systems/save/SaveSystem.ts`、`Settings.ts`
- `game/scripts/verify-save.mjs`（Node 单元校验，并入 `npm run test`）

## 验收标准
- [ ] 进入 S1、S2、S3 时各写一次存档；刷新页面后「继续」回到对应场景入口。
- [ ] 在 S2 解完谜题 3 后刷新，「继续」回到 S2 入口，谜题 3 为未解状态。
- [ ] 手动把存档 version 改成 0 或写入非法 JSON，主菜单提示「存档无法读取」且不崩溃，「继续」隐藏。
- [ ] 隐私模式（或模拟 localStorage 抛错）下可正常游玩，主菜单有「进度不会保存」提示。
- [ ] 修改设置后刷新仍保留；点「新游戏」不清除设置。
- [ ] `verify-save.mjs` 覆盖：正常读写、版本不匹配、非法 JSON、写入失败，全部通过。
