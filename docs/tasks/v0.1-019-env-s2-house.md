# v0.1-019 S2 守灯人小屋场景大件（含室内）

- **负责人**：美术
- **里程碑**：M6（建议 M4 期间开工）
- **依赖**：014（白盒对位）
- **工时估算**：6–8 人日

## 背景
GDD §5.3 第二幕（家里一切照旧，餐桌上两只杯子一只倒扣）、§6 S2（布局、窗口取景、引导：窗口暖光只来自汐放在二层书桌上的风灯）、§12.2。style-guide §5（北欧/英伦海岸，朴素、旧、实用）。通用交付规范见 `v0.1-index.md`。

## 具体内容
| 资源 | 文件 | 要求 |
|---|---|---|
| 守灯人小屋外观 | `env-keeper-house-ch1.glb` | 两层石屋，外轮廓 8 m × 6 m；一层地面 y = 0、二层地面 y = 3.0；外墙、屋顶（石板瓦）、烟囱、门窗；屋后北墙预留光感锁安装位（y = 0.85，已交付模型的 `light-lock-socket` 在 y = 1.2，需下移到 0.85（制作人 2026-10-29 裁定））和地窖门洞 |
| 小屋室内 | `env-keeper-house-ch1-interior.glb` | 一层厨房兼起居（餐桌 0.75 m 高，两只杯子一只倒扣）、木楼梯、二层卧室（床、书桌 0.75 m 高，**书桌上风灯 socket 位**——汐读日志时把风灯放在这里，见 014；东侧小窗朝院子透出暖光）；二层西窗窗台 y = 3.9，窗框是谜题 4 的取景框，**窗框位置以 014 白盒为准** |
| 地窖 | `env-cellar-s2.glb` | 小地窖，放钥匙和草图的木架；架面高约 1.1 m（离地窖地面），在交付说明里注明架面高度和 `key-socket` / `shelf-interact` 的位置，并注明拾取钥匙用 017 的哪一套拾取动作（制作人 2026-10-29 裁定） |
| 小院石墙 | `env-courtyard-wall-s2.glb` | 石墙小院、两个灯台基座位置、晾衣架（`env-laundry-rack.glb`，挡住西灯台光路，必须带 `-collider` 以挡光） |
| 崖顶地形与崖径 | `env-clifftop-s2.glb` | 30 m × 25 m 平台，南侧石阶顶，西侧崖边坡地（白石分布区，距西窗 12–20 m），北侧崖径通往 S3 |
| 室内小物 | （见 027） | 杯子、灶台、书本等小物件在 027 做，本单只做家具大件 |

- 室内外分开两个 GLB，便于室内单独烘焙光照（029）。
- 窗玻璃用简单透明材质，雨后湿痕；室内是阴天冷光为主，暖光只来自二层书桌上的风灯（程序动态光）。
- 家具老旧、用心但不堆砌：style-guide §0「精致体现在少量物件做到极致」。

## 验收标准
- [ ] 层高、窗台、灯台基座、光感锁安装位（y = 0.85）、桌面高度与本单及 014 白盒一致（误差 ≤ 5 cm）。
- [ ] 所有角色站位节点（`-interact`，含书桌站位 `desk-interact`、床、西窗）都在地面上（y = 所在楼层地面，误差 ≤ 2 cm）；已交付的 `desk-interact` 在 y = 3.95，需放到二层地面 y = 3.0（制作人 2026-10-29 裁定）。
- [ ] 地窖钥匙木架架面高约 1.1 m（误差 ≤ 3 cm），交付说明写明架面高度。
- [ ] 从 014 的 `viewpoint-s2` 节点位置看出去，窗框完整框住崖边白石区域（在 Blender 里用该节点放相机、FOV 30° 截图附在交付说明）。
- [ ] S2 静态大件 LOD0 总和 ≤ 4M、LOD1 ≤ 2.3M、LOD2 ≤ 1M 三角面（style-guide §8 `sceneVisibleTris` 的静态环境份额）。
- [ ] 每件有 LOD、`-collider`、UV2；室内楼梯台阶高 ≤ 0.2 m，角色可走。
- [ ] 晾衣架碰撞体能挡住光束（与 014 一起测试）。
- [ ] 贴图 KTX2，环境贴图 ≤ 2048。
