# v0.1-003 第三人称相机

- **负责人**：程序
- **里程碑**：M4
- **依赖**：001、002
- **工时估算**：3–4 人日

## 背景
GDD §4（相机规则，全表）、§3（右键观察）、§7 谜题 4（视角观察）。现有 `CameraFollowSystem` 已有 yaw/pitch 环绕、平滑跟随、射线遮挡拉近，在此基础上扩展，不重写。

## 具体内容
1. **探索模式**（按 GDD §4 表格，参数进 `src/config/gameplay.ts` 的 `camera` 段）：
   - 跟随点：角色头部高度（1.35 m），肩后偏右 0.4 m。
   - 距离默认 4.0 m，滚轮 2.5–6.0 m；俯仰 -35° 到 +55°。
   - 遮挡：改成**球形扫掠**（半径 0.2 m）检测，遇墙前拉，恢复平滑 0.25 s；狭小室内（触发体 `-indoor` 标记）自动把最大距离限到 2.0 m。
   - FOV 55°；小跑时 +3°（0.3 s 过渡）。
   - 自动回正：默认关；设置可开，开启后静止 8 秒向场景配置的「推荐构图」方向极慢漂移。
2. **观察模式**（按住右键）：FOV 0.3 s 收窄到 30°，鼠标灵敏度 ×0.5，通知 PostFX 开景深（焦点 = 屏幕中心射线命中点）。景深实现在 026，这里只发事件 `camera:observe {active, focusDistance}`。
3. **机关模式**：`camera.enterPuzzleView(viewNode)`，0.6 s 平滑过渡到机关的预设机位（GLB/白盒中的 `-cam` 空节点：位置 + 朝向），可在预设朝向 ±20° 内用鼠标小范围转动（如果该机关的鼠标被用于旋转，则改为不可转动，由机关配置决定）；退出时 0.6 s 回到探索相机，保持进入前的 yaw/pitch。
4. **观察点**（谜题 4 用）：`ViewpointTarget` 组件（观察点区域 + 目标方向 + 容差 6°、渐显范围 12°），每帧输出 0–1 的「对准度」，供谜题逻辑和材质使用。
5. **演出镜头接口**：`camera.playCutscene(track)` 接收镜头轨道（关键帧位置/朝向/FOV/时长，或 GLB 中相机动画），结束后 0.8 s 平滑交还；交还时保持演出前的朝向。演出本身在 035 实现，这里只做接口。
6. **建立镜头**：场景进入时播放 3 秒建立镜头（场景配置一段轨道），结束交还控制。

## 验收标准
- [ ] 默认距离 4.0 m，滚轮可在 2.5–6.0 m 调节；俯仰被限制在 -35° 到 +55°。
- [ ] 角色贴墙或走进窄门时相机不穿墙，离开后 0.25 s 内平滑恢复。
- [ ] 进入标记为 indoor 的区域时相机距离 ≤ 2.0 m。
- [ ] 按住右键：FOV 平滑收窄到 30°，松开恢复 55°。
- [ ] 小跑时 FOV 变为 58°，停下恢复。
- [ ] 测试机关：按 E 后相机 0.6 s 过渡到预设机位，右键退出后回到原来的视角朝向。
- [ ] 测试观察点：对准度在偏差 ≤6° 时为 1，12° 时为 0，中间线性；开发模式 HUD 可显示数值。
- [ ] 演出接口：播放一段 5 秒测试轨道，结束后 0.8 s 平滑交还且朝向与演出前一致。
- [ ] 场景进入时有 3 秒建立镜头，期间玩家无法移动。
