- **负责人**：美术

- **依赖**：016（风格统一）
- **工时估算**：1.5–2 人日

## 背景
GDD §5.2（父亲只在信件、日志和回忆里出现）、§12.2（只在回忆演出中出现的剪影/半透明形象）、§5.3（第一章结尾演出可短暂出现回忆剪影，由 035 决定是否使用）。预算按 style-guide §8 `npcCharTris`（极致 60k / 高 40k / 标准 25k）。

## 具体内容
- 成年男性守灯人，7–7.5 头身（style-guide §4），旧油布雨衣（就是后来改小给汐的那件，带短披肩；兜帽放下搭在披肩后，领型、口袋、扣位和接缝与汐那件一致；未褪色 `#566370`，比汐的深一档，无补丁、不卷袖；父亲扣上穿、左襟压右襟，汐敞开穿；预览 `art/models/characters/preview/char-father-r3-turnaround.png`）、毛线帽，40 岁上下，高约 1.79 m，不留胡须（美术样张 `art/models/characters/preview/char-father-shape-*.png`，策划 2026-10-30 确认）；面部不需要精细（回忆里多为背影或剪影）。
- `char-father.glb`：`_lod0` ≤ 60k、`_lod1` ≤ 25k（同时满足高 40k / 标准 25k）。贴图 2048，材质 ≤ 2。
- 动画 `char-father-anims.glb`：`father-stand-gaze`（站在灯室眺望）、`father-walk-away`（走向码头背影）、`father-hand-on-head`（抚摸孩子头，回忆片段用）。
- 渲染方式（半透明 / 雾化剪影）由程序在 035 用材质实现，模型按普通角色交付。
