## 背景
GDD §12.1、§12.2（通用：海面、雨、雾、天空按时段预设；特效：体积光束、反射光斑、水花、雨滴溅落、雾流动、灯塔点亮光晕）。style-guide §2（色板）、§3（光照、天空与雾、光束、后处理）、§9（命名：`art/textures/lut/lut-overcast-dusk.png` 等）。

## 具体内容
| 资源 | 文件 | 说明 |
|---|---|---|
| 云层 | `tex-sky-clouds-overcast-albedo.ktx2` | 手绘低饱和厚重层云，可平铺滚动，2048 |
| 雾墙 / 雾贴片 | `tex-fog-card-a-albedo.ktx2` ~ `tex-fog-card-c-albedo.ktx2` | 3 种雾片（带 alpha），1024 |
| 雨圈法线 flipbook | `tex-rain-ripple-normal.ktx2` | 水面/水洼雨圈，8×8 帧，1024 |
| 雨丝 / 溅落 | `tex-rain-streak-albedo.ktx2`、`tex-rain-splash-albedo.ktx2` | 512 |
| 镜头水滴 | `tex-lens-droplets-normal.ktx2` | 特写镜头用，1024 |
| 水面法线 | `tex-water-normal.ktx2` | 平静海面微波，2048 |
| 岸边泡沫 | `tex-water-foam-albedo.ktx2` | 1024 |
| 光束噪声 / 光斑 | `tex-beam-noise-albedo.ktx2`、`tex-beam-spot-albedo.ktx2` | 光束内粉尘、墙面光斑 |
| 灯塔点亮光晕 | `tex-glow-lighthouse-albedo.ktx2` | 结尾演出 |
| 调色 LUT | `art/textures/lut/lut-overcast-dusk.png`、`lut-overcast-after-rain.png`、`lut-rain-night.png`、`lut-after-lit.png` | 冷调、压饱和、暗部偏蓝；after-lit 允许暖色更多 |
| Ramp | `tex-ramp-char.ktx2`、`tex-ramp-env.ktx2`、`tex-ramp-metal-wet.ktx2` | 256×1，角色 2 级 / 场景 3 级 / 湿金属高光 |

- LUT 格式和尺寸与程序约定（建议 32³ 展开的 1024×32 PNG），先在 026 里试一张再批量出。
- 颜色严格用 style-guide §2 色板。
