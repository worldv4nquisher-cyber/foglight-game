# v0.1-034 正式资源接入（角色、场景、道具）

- **负责人**：程序
- **里程碑**：M6
- **依赖**：013、014、015、016、017、018、019、020、021、022、023、027、029
- **工时估算**：4–6 人日

## 背景
GDD §12（美术需求）、§14（预算以 style-guide §8 为准）。白盒（013–015）已可通关，本单把白盒替换为正式资源，保证玩法不变。

## 具体内容
1. **资源管线**：`art/` 交付物同步到 `game/public/assets/`（脚本 `npm run assets:sync`，只拷贝 GLB/KTX2/WebP/OGG）；构建脚本按 style-guide §8 生成低档贴图变体（角色/重点道具 4096 → 2048；环境 2048 → 1024 给标准档），运行时按档位选择。
2. **主角**：`char-xi.glb` + `char-xi-anims.glb` 接入，动画状态机（idle / walk / jog / stairs / push / 各交互动作 / 提灯变体），根据速度混合；风灯挂到 `hand_r_socket`。主角 LOD 按档位选最高级：极致 `_lod0`、高/标准 `_lod1`（满足 §8 `heroCharTris`，按拆单裁定第 4 条高档、标准档均为 50k）。在 `lod.ts` 中加「按档位最低 LOD」支持（角色离相机始终很近，不能只靠距离）。
3. **场景**：用正式 GLB 替换白盒几何，碰撞改读 `-collider`，交互点读 `-interact`，特殊节点（`-mirror-plane`、`-receiver`、`-emitter`、`-socket`、`-waterline` 等）接到 004/011/012 组件上；`layout.ts` 中的坐标与正式模型对齐。
4. **装饰与植被**：礁石模块、装饰物用 InstancedMesh/BatchedMesh；草按 `grassDensity`。
5. **光照贴图**：接入 029 的 lightmap（UV2）与光照探针。
6. 白盒回归：三个场景 5 道谜题在正式资源下重新通关一遍。

## 验收标准
- [ ] 三个场景无白盒几何残留；5 道谜题在正式资源下全部可通关。
- [ ] 所有 puzzleCritical 物体三档都是 LOD0（`__lods()`）。
- [ ] F3 面板：每个场景最差机位下，极致档三角面 ≤ 6M、draw call ≤ 2000；高档 ≤ 3.5M / ≤ 1200；标准档 ≤ 1.5M / ≤ 600（style-guide §8）。
- [ ] 主角在极致档用 `_lod0`，高/标准档用 `_lod1`；动画切换无明显跳帧，移动无明显滑步。
- [ ] 标准档使用 1024 环境贴图、高/标准档角色 2048 贴图（开发模式可查看实际加载的贴图尺寸）。
