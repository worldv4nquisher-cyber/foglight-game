## 背景
GDD §3（移动）、§9（数值）、§15（不做跳跃/攀爬/游泳，跨越由交互点自动完成）。现有 `PlayerController` + `KinematicBody` + `PhysicsSystem`（AABB 分轴碰撞、重力、跳跃）只适合方块原型，不支持斜坡、台阶、螺旋楼梯（S3）和三角网格场景。

## 具体内容
1. 替换碰撞为**胶囊 vs 静态三角网格**：建议 `three-mesh-bvh`（MIT，capsule-vs-BVH 官方示例可直接参考）；也可换 Rapier（`@dimforge/rapier3d-compat`），二选一，写进 README。要求：
   - 可走斜坡 ≤ 40°，可上台阶 ≤ 0.3 m（S3 螺旋楼梯、S1 石阶）。
   - 楼梯上移动速度固定：竖直约 0.55 m/s（台阶 0.2 m / 踏面 0.26 m 时水平约 0.715 m/s），按不按 Shift 都一样，对应 017 `xi-stairs-up/down`；S3 底层到灯室单程约 40 s（制作人 2026-10-29 裁定）。
   - 碰撞体来源：GLB 里名字以 `-collider` 结尾的网格（隐藏不渲染）；没有 collider 节点的模型不参与碰撞。白盒阶段可用代码生成的盒子/网格。
   - 支持**动态碰撞体**：水位相关的通路（潮汐，见 011）和浮台（013）可以在运行时开关或移动。
2. 移动参数（写入 `src/config/gameplay.ts`，GDD §9 初值，所有玩法数值集中这里）：
   - 慢走 1.6 m/s（默认），小跑 3.2 m/s（按住 Shift），转身 540°/s，加速到目标速度 ≤ 0.15 s。
   - 去掉跳跃；保留重力，只用于贴地和走下台阶。
   - 相对相机方向移动；角色朝向平滑转向移动方向。
3. 角色尺寸改为 13 岁女孩：胶囊高 1.50 m、半径 0.25 m（与 016 的 `char-xi.glb` 身高一致，脚底原点、朝向 +Z）。删除 demo 的 1.8 m 胶囊参数。
4. **自动跨越点**（GDD §7 谜题 2）：提供 `TraversalLink` 组件（起点、终点、触发条件），玩家走进起点区域按 E 或直接前进时，角色沿预设路径平滑移动过去（播放 017 的跨步动画，白盒阶段直接位移）。
5. **强制送回**：提供 `player.teleportTo(point, {fade: 0.5})`，黑场 0.5 s（谜题 1、5 的涨潮送回）。
6. 空气墙：GLB 中 `-wall` 后缀的网格作为不可见边界。

## 验收标准
- [ ] 测试场景里：30° 斜坡能走上去，45° 斜坡走不上去；0.25 m 台阶能自动上去，0.4 m 台阶挡住。
- [ ] 测试场景里放一段半径 2.5 m、台阶高 0.2 m 的螺旋楼梯，角色能连续走上去不卡顿、不抖动。
- [ ] 慢走速度 1.6 m/s、小跑 3.2 m/s（开发模式 HUD 显示速度，误差 ±5%）。
- [ ] 角色贴墙行走不会穿模、不会卡死；贴墙滑动顺畅。
- [ ] 运行时关闭/开启一个动态碰撞体，角色立即能/不能通过。
- [ ] TraversalLink 测试：走到起点按 E，角色 1–2 秒内平滑到达终点，期间不接受移动输入。
- [ ] `teleportTo` 有 0.5 s 黑场，不出现穿模或掉落。
- [ ] 1440p 极致档下碰撞计算每帧 ≤ 0.5 ms（开发模式性能面板）。
