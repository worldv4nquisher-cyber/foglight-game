# v0.1-016 主角「汐」模型、贴图与绑定

- **负责人**：美术
- **里程碑**：M6（建议 M4 期间即开工，程序在 M4/M5 用胶囊占位）
- **依赖**：无（风格依据 style-guide §1、§2、§4；角色参考图 `art/style/concept-ch1-xi-character.png` 已有）
- **工时估算**：5–7 人日

## 背景
GDD §5.2（汐：13 岁女孩，话少，藏青粗毛衣、灰蓝油布斗篷、黄铜风灯）、§12.2（主角资源）、§14（面数/贴图以 style-guide §8 为准）。style-guide §4 已由美术改为 13 岁女孩汐（约 6 头身），以 §4 为准。

## 具体内容
1. **角色参考图**：以已有的 `art/style/concept-ch1-xi-character.png` 为准（正、背、脸部特写；背面漏画风灯，以正面为准，见 style-guide 样张表），13 岁女孩、约 6 头身，服装按 style-guide §4。
2. **模型**：三渲二半写实，按 style-guide §1（角色 2 级明暗、反向法线外扩描边需要的平滑法线烘焙到顶点色或 UV2 通道）。
   - 身高 1.50 m，脚底原点，朝向 +Z，单位米（与 002 胶囊一致）。
   - 头发分簇 10–20 簇；斗篷单独网格，带摆动骨骼链。
   - 风灯 **不** 做在角色网格里，单独作为 `prop-lantern-brass.glb`（见 021），手部骨骼加挂点 `hand_r_socket`。
3. **面数（制作人拆单裁定第 4 条（`docs/releases/v0.1.md`「拆单裁定」）：极致 120k / 高 50k / 标准 50k；美术同步把 style-guide §8 `heroCharTris` 高档由 80k 改为 50k）**，按 README「LOD 与解谜关键物体」命名放在同一个 GLB：
   - `char-xi_lod0` ≤ 120k 三角面（极致档近景）；
   - `char-xi_lod1` ≤ 50k（高、标准档共用）；
   - `char-xi_lod2` ≤ 25k（演出远景）。
4. **骨骼**：人形骨骼 ≤ 80 根（含头发、斗篷摆动骨），命名用英文小写下划线；三级 LOD 共用同一骨架。
5. **贴图**（style-guide §1 材质规则：手绘质感漫反射，法线只保留中大尺度，粗糙度区分干湿）：
   - `tex-xi-albedo.ktx2`、`tex-xi-normal.ktx2`、`tex-xi-orm.ktx2`：4096（`textureMaxSize` 极致档上限；高/标准档的 2048 版本由程序构建脚本自动生成，见 034）。
   - `tex-xi-sdf-face.ktx2`：SDF 面部阴影图（style-guide §4、§7.2）。
   - `tex-xi-ramp.ktx2`：256×1 明暗 ramp。
   - 湿润遮罩：斗篷区域在 orm 或顶点色里预留湿度通道（被雨淋湿时变深、变光滑）。
   - 材质 ≤ 3 个（身体/衣服、头发、脸），控制 draw call。
6. 色值按 style-guide §2「角色色」；全身唯一暖色是风灯（不在本模型内）。
