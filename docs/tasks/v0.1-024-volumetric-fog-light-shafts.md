# v0.1-024 体积雾、雾墙与体积光束

- **负责人**：程序
- **里程碑**：M6
- **依赖**：009、012
- **工时估算**：5–7 人日

## 背景
GDD §12.1（浓雾、留白）、§14（体积雾/光束分档）。规范以 style-guide §3.2（高度雾 + 距离雾，远景 3–5 层雾墙）、§3.3（光束：极致/高 raymarch，标准用加法锥形网格 + 公告板 + soft particle）、§8（`fogMode`、`fogCards`、`lightShafts`、`softParticles`）为准；帧时间预算 §8：体积雾和光 ≤ 3 ms（极致 1440p）。

## 具体内容
1. **体积雾**：froxel 体素雾（极致 160×90×128、高 80×45×64 半分辨率），高度雾（海面最浓向上变淡）+ 距离雾；受风灯、灯塔、谜题光束照亮。标准档 `cards`：假体积贴片。
2. **雾墙贴片**：远景 3–5 层（§8 `fogCards`：极致 5 层 + ≤ 20、高 5 层 + ≤ 30、标准 4 层 + ≤ 40），越远越白越平，缓慢漂移；用 028 的雾贴图。 最远一层放在 250 m 以内（标准档视距；三档视距 600 / 400 / 250 m 见 009），切档时（`quality:changed`）雾墙层次不跳变。
3. **光束**：替换 012 白盒版 `BeamRenderer`：极致 raymarch 64 步、高 32 步半分辨率、标准加法锥形网格 + 公告板（镜头与锥轴夹角过小时淡出）。用于：风灯光锥、谜题 3 暖色光路、谜题 5 冷白光路（点火瞬间 1 s 转暖）、灯塔旋转主光束（结尾）。
4. **谜题可读性要求**（GDD §14）：三档下谜题光路的路径、落点光斑、接收器反馈一致清晰，不能因降档读不出光路。
5. 雾参数接入气氛预设（026）。

## 验收标准
- [ ] 三档雾模式与参数符合 style-guide §8（`fogMode`、`fogCards`、`lightShafts`）。
- 自测参考（不作验收项，帧率/帧时间由用户 M8 实机验收，见拆单裁定第 8 条）：极致档 1440p RTX 3060 级：体积雾 + 光束 GPU 时间 ≤ 3 ms。
- [ ] 远景可见 3–5 层雾墙，远处灯塔剪影若隐若现。
- [ ] 三档下谜题 3、5 的光路都能清楚看出走向与落点（制作人三档各通一遍谜题 3、5）。
- [ ] 谜题 5 点火瞬间光束 1 s 内由冷白转暖。
- [ ] 标准档光束从任意角度看无明显穿帮（锥体贴片淡出生效）。
