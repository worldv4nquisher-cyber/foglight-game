## 背景
GDD §12.1（三渲二半写实）。实现规范以 style-guide §1（明暗分级、描边、高光、边缘光、材质）、§7.2（Toon 材质）、§7.3（描边方案）为准；分档参数见 §8（`outlineHull`、`outlinePost`）。

## 具体内容
1. **Toon 材质**（`onBeforeCompile` 扩展 `MeshStandardMaterial`，或 TSL 节点；如 009/框架决定走 WebGPU 路线则用 TSL，同一套代码兼容 WebGL2）：
   - `NdotL` 经 ramp 贴图阶梯化（角色 2 级、场景 3 级），保留阴影贴图和光照贴图输入；暗部乘阴影染色（角色 `#6C7488`）。
   - 风格化阶梯高光（金属、湿表面）；头发 Kajiya-Kay 各向异性高光再阶梯化。
   - Fresnel 边缘光：默认冷色 `#DCE1E4` 低强度；靠近风灯/灯塔暖光时转琥珀色（按最近暖光距离插值）。
   - 脸部 SDF 阴影（`tex-xi-sdf-face.ktx2`）。
   - 湿度：顶点色或遮罩控制粗糙度和颜色变深；全局 `uWetness` + `uTideLevel` 湿痕线。
   - IBL 只取漫反射 SH。
2. **描边**：
   - 反向法线外扩：平滑法线读顶点色；屏幕空间恒定线宽（角色约 1.5 px @1080p，1440p 等比）；线色 = 固有色压暗 60% 偏冷，不用纯黑。按 §8 `outlineHull` 分档决定哪些物体描。
   - 后处理边缘检测：法线 + 深度 + 物体 ID（MRT），线约 1 px，随距离和雾淡出；按 §8 `outlinePost`（极致 300 m 含 ID / 高 150 m 无 ID / 标准关闭）。外扩描边的物体在 ID 缓冲里排除，避免描两遍。
3. GLB 加载后按材质名或 extras 自动替换为 toon 材质（约定写进 README：`mat-char-*`、`mat-env-*`、`mat-prop-*`）。

## 验收标准
- [ ] 角色明暗 2 级、场景 3 级，交界线硬但带 1–2 px 软过渡（对照 style-guide §1 截图）。
- [ ] 角色描边约 1.5 px（1080p），颜色非纯黑；场景描边随距离/雾淡出。
- [ ] 三档描边范围符合 style-guide §8 `outlineHull` / `outlinePost`；标准档无后处理描边。
- [ ] 角色靠近风灯时边缘光转琥珀色，远离恢复冷色。
- [ ] 脸部阴影无难看的鼻影/脸颊块（SDF 生效）。
- 自测参考（不作验收项，帧率/帧时间由用户 M8 实机验收，见拆单裁定第 8 条）：极致档 1440p：描边总开销 ≤ 1.5 ms（style-guide §7.3 后处理描边约 0.5–1 ms），F3 面板或 GPU 计时验证。
