# v0.1-026 后处理链、调色 LUT 与气氛预设

- **负责人**：程序
- **里程碑**：M6
- **依赖**：009、023、024、025；LUT 贴图来自 028
- **工时估算**：2–3 人日

## 背景
GDD §12.1（低饱和冷色、暖色平时 ≤ 15%、点灯高潮可到约 30%；各场景天气）、§4（观察模式/机关/演出开景深）。规范以 style-guide §3.1（时段预设 `overcast-dusk` / `rain-night` / `after-lit`）、§3.4（后处理顺序）、§8（`dof`、`bloom`、`lut`/`toneMapping`、`filmGrain`/`vignette`、`antialias`）为准。现有 `PostFX.ts`（N8AO → Bloom → ACES → 调色 → 暗角 → 颗粒 → SMAA）和 `config/atmosphere.ts`（`melancholy-dusk` / `lonely-night`）在此基础上调整。

## 具体内容
1. 后处理顺序按 style-guide §3.4：GTAO → 体积雾/光合成 → SSR/平面反射 → 描边 → 景深 → Bloom（高阈值，只让暖光和光束发光）→ 色调映射 **AgX**（替换现有 ACES）→ LUT → 胶片颗粒（0.03–0.05）→ 暗角 → TAA/SMAA。分档按 §8。
2. 气氛预设改名对齐指南（制作人拆单裁定第 6 条同意）：`overcast-dusk`（S1 默认）、`rain-night`（备用）、`after-lit`（点灯后）；另加 `overcast-after-rain`（S2 阴天雨停，基于 overcast-dusk 调雨量和湿度）。每个预设：主光颜色强度、雾密度颜色、LUT、雨量、湿度。`?atmo=` 调试参数保留。
3. **景深**：监听 003 的 `camera:observe`、机关模式、演出事件开启（极致 bokeh / 高 高斯只在过场 / 标准关）。
4. **点灯转暖**：监听 `lighthouse:ignited`，在 3–5 s 内从当前预设过渡到 `after-lit`（雾稍散、暖光束扫过海面），暖色占比可到约 30%。
5. 开发工具：`?warmth=1` 在 F3 面板显示画面暖色像素占比（色相 20°–50°、饱和度 > 0.35 的像素比例），供美术和制作人检查 ≤ 15% / ≤ 30%。
