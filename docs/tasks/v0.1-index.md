## 3. 关键路径

- **程序是瓶颈**：程序只有一人，23 张单基本只能串行，程序总工时 69–93.5 人日就是 v0.1 的最短工期。美术 53.5–74 人日可以并行，只要在 034 开工前交齐即可。
- **依赖链**（不考虑人手、只看依赖时最长的一条）：001 → 002 → 003 → 004 → 012 → 015（S3 白盒）→ 020（灯塔大件）→ 027 → 029（烘焙）→ 034（资源接入）→ 035（演出）→ 036 → 037。
- **美术必须按时交付的节点**：016/017（主角）、018–022（场景大件与解谜道具）、027、029 必须在程序做完 023–026 之前交齐，否则 034 会空等。建议美术在程序做 M5 白盒期间做完 016–020，程序做 M6 渲染时美术做完 021/022/027/029。
- **最容易超期的风险**：023/024（自定义着色与体积雾在 WebGL2 上的性能）、015（谜题 5 多层光路）、029（烘焙返工会拖住 034）。

## 5. 美术交付通用规范（018–022、027、029、031 引用）

1. **单位与朝向**：1 单位 = 1 米；Y 轴向上（glTF 标准），模型正面朝 +Z；原点在物体底部中心（可旋转的机关原点放在旋转轴上）。
2. **命名**：全部小写英文 + 短横线，严格按 style-guide §9。模型放 `art/models/characters|props|env/`，贴图放 `art/textures/tex-<对象>-albedo|normal|orm|ramp|sdf-face|lightmap.ktx2`，LUT 放 `art/textures/lut/`，UI 放 `art/ui/`，源文件放 `art/source/`。
3. **LOD**：同一 GLB 内 `<名>_lod0/_lod1/_lod2`，每级三角面约减半（`game/src/render/lod.ts` 读取；`node scripts/verify-lod.mjs` 自检）。
4. **puzzleCritical 物体**：根节点自定义属性 `puzzleCritical=true`，**只交 LOD0，任何档位不降级**；必须带 `-collider`（简化碰撞体）和 `-interact`（交互点，含朝向）；旋转机关的枢轴在旋转轴上；平滑法线写入顶点色（给外扩描边）；贴图 2048；三角面 ≤ 15k（潮汐钟 ≤ 20k、白石组 ≤ 20k、风灯 ≤ 8k、钥匙 ≤ 3k）。
5. **特殊节点**：`<名>-collider`（碰撞，不渲染）、`<名>-wall`（只挡人的空气墙）、`<名>-interact`（交互点）、`<名>-cam`（机关镜头机位）；各单另有约定的（`-mirror-plane`、`-receiver`、`-emitter`、`-socket`、`-waterline`、`viewpoint-s2` 等）以单内为准。
6. **UV**：UV0 为贴图；静态环境物体需要 UV2（光照贴图，不重叠，留 2–4 px 间距）。
7. **压缩**：GLB 用 Meshopt 压缩；贴图用 KTX2（颜色贴图 ETC1S 或 UASTC，法线/ORM 用 UASTC）。美术**只交最高档分辨率**（角色/重点道具 4096 或单内规定值，环境 ≤ 2048），低档变体由程序构建脚本生成（034）。
8. **材质**：每件 ≤ 3 个材质，按 `mat-char-* / mat-env-* / mat-prop-*` 命名（023 据此自动替换 toon 材质）；模块化部件尽量共用材质与图集，方便实例化。
9. **光**：环境资源**不带任何暖色自发光或灯光**（style-guide §0）；暖光只有汐的风灯、谜题 3 光路和点火后的灯塔，都由程序实时生成。
10. **预算**：所有三角面、贴图、draw call 以 style-guide §8 为准。每个场景静态环境份额：LOD0 ≤ 4M、LOD1 ≤ 2.3M、LOD2 ≤ 1M（占 §8 `sceneVisibleTris` 6M/3.5M/1.5M 的环境部分，其余留给角色、道具、植被和特效）。
11. **素材来源**：只用自制或可商用/免版权素材，美术登记到 `art/CREDITS.md`，音频登记到 `audio/CREDITS.md`。
12. **交付自检**：在 `game/` 跑 `npm run check` 和 `node scripts/verify-lod.mjs <文件>` 通过后再提交。
