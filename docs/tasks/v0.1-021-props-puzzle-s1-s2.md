## 背景
GDD §7 谜题 1–4、§8 机制库、§12.2。style-guide §1（重要道具用反向法线外扩描边，需平滑法线）、§8（重点道具贴图上限 4096 / 2048 / 2048）。程序侧 `src/render/lod.ts` 已实现：节点或祖先带 `puzzleCritical` 自定义属性 → 三档固定 LOD0，低级 LOD 被丢弃（见 game/README「LOD 与解谜关键物体」）。通用交付规范见 `v0.1-index.md`。

## puzzleCritical 通用要求（本单所有物体）
- 根节点 Blender 自定义属性 `puzzleCritical = true`，导出勾选 Custom Properties；**只做 LOD0**（不做低级 LOD）。
- 三角面建议 ≤ 15k / 件（潮汐钟 ≤ 20k、白石组整组 ≤ 20k），计入场景 `sceneVisibleTris`。
- 贴图 2048（满足 style-guide §8 三档上限），可多件共用一张图集。
- 必须带 `-collider`（简化碰撞）和 `-interact`（角色站位空节点，+Z 指向物体）；旋转件的原点放在旋转轴上。
- 需要外扩描边：平滑法线烘焙到顶点色。

## 验收标准
- [ ] 每个文件根节点带 `puzzleCritical=true`；加载后开发模式 `__lods()` 显示固定 LOD0（三档切换都不降级）。
- [ ] 每件都有 `-collider` 和 `-interact`；表中列出的特殊节点（`-emitter`、`-socket`、`-mirror-plane`、`-receiver`、`-waterline`、`bell-swing`、`mirror-pivot`、`dial-0/1/2`、`gate-door`）全部存在且命名一致。
- [ ] 镜子 `-mirror-plane` 的 +Z 与镜面法线一致（程序用 012 的 `?beamDebug=1` 验证反射正确）。
- [ ] 观察模式（固定眼位 (0.95, 4.35, 1.0)、FOV 30°）下能清楚读出「317」；观察模式外，从玩家可到达的任何第三人称位置看都读不出 317（制作人裁定 17，在游戏中验证）。
- [ ] 三角面：每件 ≤ 15k（钟 ≤ 20k、白石组 ≤ 20k、风灯 ≤ 8k）；贴图 ≤ 2048。
- [ ] 潮汐钟在阴天光照下有明显冷色高光，开场建立镜头中可一眼看到（制作人主观验收）。
