# v0.1-025 阴影、水面潮汐表现、反射与雨

- **负责人**：程序
- **里程碑**：M6
- **依赖**：009、011
- **工时估算**：5–6 人日

## 背景
GDD §12.1（天气：S1 黄昏细雨、S2 雨后、S3 暴雨前）、§14。规范以 style-guide §3.1（主光冷色、同屏带阴影暖光 ≤ 2 盏）、§3.2（雨）、§7.4（阴影）、§7.5（水面）、§8（`shadowType`、`pointLightShadows`、`reflections`、`ao`、`rainParticles`）为准；帧时间：几何和阴影 ≤ 7 ms、反射 ≤ 2 ms（极致 1440p）。现有框架：PCF 软阴影分档、N8AO、GPU 雨（`Rain.ts`）、波浪水面（`Water.ts`）。

## 具体内容
1. **阴影**：主方向光 CSM（极致 4 级 4096 + PCSS + 接触阴影；高 3 级 2048 + PCF；标准 2 级 2048 + PCF）；静态物体阴影走光照贴图（029），CSM 只投动态物体 + 近景。风灯点光阴影（极致 2 盏 1024 / 高 1 盏 1024 / 标准 1 盏 512），只在附近开启。
2. **AO**：极致 GTAO 全分辨率、高半分辨率、标准只用烘焙 AO（现有 N8AO 可保留作 GTAO 实现，参数对齐 §8）。
3. **水面**：按 `uTideLevel`（011）驱动高度；平面反射（极致 1.0× / 高 0.5× / 标准 0.25× + 反射探针）+ 湿地面 SSR（极致全、高半分辨率）；雨圈法线 flipbook；深度着色（浅滩透明 → 深水暗潮色 `#283139`）；岸边泡沫线；湿痕线随水位移动。
4. **雨**：GPU 粒子（极致 30k + 雨圈 + 镜头水滴 / 高 15k + 雨圈 / 标准 6k + 雨圈），按场景天气预设开关和调量。
5. 湿表面：全局 `uWetness`（023 材质读取）。
