## 背景
GDD §3（E 交互、机关操作按键）、§7 通用规则（R 重置、无失败惩罚）、§9（交互距离 1.8 m、±60°、提示距离 3.5 m）、§10（HUD 交互提示、机关模式按键提示条）。现有 `Hud` 有 `hud-prompt` 互动提示、`Lighthouse` 有 demo 版 E 键点亮，可复用 UI 部分，逻辑需要通用化。

## 具体内容
1. **Interactable 组件**（所有可交互物体共用）：
   - 字段：`id`、`kind`（`inspect` / `read` / `pickup` / `place` / `use` / `hold` / `push` / `puzzle`）、`prompt` 文本 ID（取 `docs/gdd/text-ch1.md` §8 的 `ui.prompt.*`，如 `ui.prompt.read` =「E 阅读」）、`textId`（inspect / read 用）、`interactPoint`（GLB 中 `-interact` 空节点：角色站位 + 朝向；没有则取物体前方 1 m）、`enabled`。
   - 判定：距离 ≤ 1.8 m 且角色朝向与物体夹角 ≤ 60°；多个候选时取「屏幕中心最近」者。
   - 3.5 m 内显示冷色交互小图标（`#A9BCC4`，style-guide §2），进入 1.8 m 可交互时显示文字提示。
2. **交互类型**：
   - `inspect`：按 E 后以字幕显示一句描述（`textId`，如 `ch1.s1.nets.inspect`），不打开阅读界面、不暂停游戏（text-ch1 §0 第 10 条）。
   - `read`：打开阅读界面（005）。
   - `pickup` / `place`：拾取/放置手持物（v0.1 只有风灯一种手持物，谜题 3）。放置只能放在指定 `-socket` 节点上。
   - `use`：单次触发（敲钟、开门、拨盘确认）。角色先自动走到 interactPoint（≤ 0.4 s 平移 + 转向），再播放动作。
   - `hold`：按住 E 持续 N 秒触发（油阀 2 s），有圆环进度。与 017 `xi-valve-hold` 对齐：按下后先对位并播 clip，圆环从 turnStart（第 16 帧，0.533 s）开始走、turnEnd（第 76 帧）满 2.0 s 触发，所以玩家实际按住约 2.53 s（不含对位）；中途松开进度归零、阀轮转回、clip 淡出到 idle（017 第 2 批 `art/models/characters/README.md`，2026-10-29 比对补写）。
   - **对位**：所有带动作 clip 的交互（`use`、`hold`、`push`、`pickup`、`place`、进入机关 `puzzle`）都先把汐放到 interactPoint、面向 +Z 再播动作（017 第 2 批 clip 都以交互点为原点）；1.8 m 交互距离不变，离交互点 ≤ 0.3 m 时用 ≤ 0.4 s 平移 + 转向，更远时先用 `xi-walk` 以 1.6 m/s 走过去（避免滑行）。
   - `push`：按住 E 时角色与物体沿预设轨道移动（浮台，0.8 m/s），松开停下；轨道终点卡位触发事件。
   - `puzzle`：进入机关模式（下条）。
3. **机关操作模式（PuzzleMode）**：
   - 进入：输入上下文切到 `puzzle`（001），相机进入预设机位（003），显示底部按键提示条：「鼠标 旋转 / Shift 精调 / Q·E 切换 / R 重置 / 右键 退出」。
   - 一个机关组包含 1–N 个 `RotatablePart`：旋转轴（单轴或双轴）、档位角（默认 15°，精调 7.5°）、角度范围、初始角度。鼠标左右（双轴时上下控制第二轴）或 A/D（W/S）旋转，按档吸附，每档发出事件（供咔哒音效）。
   - 当前部件微弱描边高亮（描边先用简易实现，正式描边在 023）。
   - R：该机关组所有部件回到初始角度。
   - 退出：右键 / Tab；Esc 进入暂停（见 001）。
4. **高亮 API**：`highlight(objectIds, seconds)`，供提示系统二级提示用（007）：物体轮廓 3 秒高亮。
5. **事件总线**：交互和机关状态变化统一通过 `EventBus` 发出（如 `interact:used {id}`、`puzzle:partRotated {group, part, angle}`），谜题逻辑（011–015）只监听事件，不直接改 UI。
6. 删除 demo `Lighthouse.ts` 中直接监听 E 键的代码，改为 Interactable。

## 验收标准
- [ ] 站在物体 1.8 m 内、面向 ±60° 内才出现「E …」提示；背对或超出 1.8 m 不出现；3.5 m 内有冷色小图标。
- [ ] 八种交互类型（含 `inspect`）在测试场景各有一例，全部可用。
- [ ] `use` 交互时角色自动走到交互点并转向，不会穿模。
- [ ] `hold`：圆环在动作的转动段走满 2 秒后触发（油阀：从 `xi-valve-hold` 第 16 帧到第 76 帧）；中途松开进度归零。
- [ ] 带动作的交互都先对位到交互点再播 clip，手与把手 / 握点 / socket 无明显错位，远处对位时不滑行。
- [ ] `push`：按住 E 物体以 0.8 m/s 沿轨道移动，到终点卡位后发出事件并不能再推。
- [ ] 机关模式：鼠标旋转按 15° 吸附，按住 Shift 为 7.5°；Q/E 切换部件且高亮跟着变；R 恢复初始角度；右键退出。
- [ ] 机关模式中按 Esc 弹出暂停菜单，继续后仍处于机关模式。
- [ ] 在机关视图或阅读视图中按 Esc 暂停 → 点「继续」后，**第一次右键同时完成两件事**：重新锁定鼠标，并退出机关/阅读视图回到自由探索（不需要先点一下画面再按一次右键）。
- [ ] `highlight()` 调用后目标物体轮廓高亮 3 秒后消失。
- [ ] demo 灯塔改为通过 Interactable 点亮，功能不变。
