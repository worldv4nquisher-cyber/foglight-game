# v0.1-017 主角「汐」动画

- **负责人**：美术
- **里程碑**：M6（模型骨架确认后即开工）
- **依赖**：016
- **工时估算**：5–7 人日

## 背景
GDD §12.2（主角动画清单）、§5.3（开场与结尾演出）、§7（敲钟、推浮台、放风灯、转镜子、按住开油阀、拨盘、谜题 5 拉点火拉杆点灯）、§9（慢走 1.6 m/s、小跑 3.2 m/s）。style-guide §0（动画节奏慢、安静、略带忧伤）。

## 具体内容
所有动画放在一个文件 `char-xi-anims.glb`（与 `char-xi.glb` 同骨架，无网格），clip 名如下（程序按名字调用）：

| clip 名 | 说明 | 循环 |
|---|---|---|
| `xi-idle` | 站立待机，偶尔搓手、缩脖子（湿冷感），≥ 6 s | 是 |
| `xi-idle-lantern` | 手提风灯待机 | 是 |
| `xi-walk` | 慢走，根运动步幅对应 1.6 m/s | 是 |
| `xi-walk-lantern` | 提灯慢走 | 是 |
| `xi-jog` | 小跑，对应 3.2 m/s | 是 |
| `xi-jog-lantern` | 提灯小跑 | 是 |
| `xi-turn-l90` / `xi-turn-r90` | 原地转身 | 否 |
| `xi-stairs-up` / `xi-stairs-down` | 上下楼梯（台阶高 0.2 m、踏面 0.26 m）：**竖直速度约 0.55 m/s**（水平约 0.715 m/s；S3 底层到灯室 21.8 m 单程约 40 s）；第 1 批 0.333 m/s 的版本作废，按 0.55 m/s 重新生成（动作仍是走，不是跑）（制作人 2026-10-29 裁定） | 是 |
| `xi-step-across` | 跨越 0.5 m 缝隙（浮台，TraversalLink） | 否 |
| `xi-push-loop` / `xi-push-start` / `xi-push-end` | 推浮台（0.8 m/s） | loop 是 |
| `xi-ring-bell` | 敲潮汐钟 | 否 |
| `xi-pickup` / `xi-place` | 拾取 / 放下（风灯、钥匙；地窖钥匙木架架面约 1.1 m，用哪一套、是否要调参数由美术在 README 注明（制作人 2026-10-29 裁定））：灯台（`prop-lantern-stand-s2`，提手 1.008 m，socket 在交互点前 0.70 m，越过 1.0 m 罩沿） | 否 |
| `xi-pickup-table` / `xi-place-table` | 第 2 批美术新增（2026-10-29 策划认可）：桌面 0.75 m（S2 书桌，提手 1.03 m，socket 在交互点前 0.45 m、偏右 5 cm，桌沿在交互点前 0.20 m），不迈步；读日志时自动放灯用 `xi-place-table` | 否 |
| `xi-operate-loop` | 双手扶着机关转动（镜子、拨盘） | 是 |
| `xi-valve-hold` | 按住转动阀门：clip 3.0 s（91 帧），其中转动段 turnStart 第 16 帧 → turnEnd 第 76 帧正好 2.0 s（= GDD 油阀 2 s），双手转阀轮 90°（从汐看逆时针为开）。**阀轮中心离汐站立面 0.70 m**（015/020/022：底层地面 y = 0.2、阀门中心 y = 0.9；第 2 批按 0.90 m 做的版本作废，按 0.70 m 重新生成，转动段仍为 2.0 s、事件帧号不变（制作人 2026-10-29 裁定）） | 否 |
| `xi-ignite-lever` | 谜题 5 点灯（用户 2026-10-29 确认改为亲手点灯）：右手仍提风灯（`hand_r_socket`），左手握住点火口旁的拉杆（握点高 1.0 m，与 022 `ignite-lever` 对齐），停顿一下再拉到底；已交付：46 帧 / 1.5 s，grip 第 15 帧、pullStart 第 22 帧、拉到底第 34 帧（1.133 s）标动画事件 `ignite`（程序在此帧发 `lighthouse:ignited`），保持到第 45 帧。动作克制，像一个郑重的决定，不要用力过猛 | 否 |
| `xi-read-loop` | 低头阅读手中的纸 | 是 |
| `xi-look-up` | 抬头仰望（灯塔、楼梯井） | 否 |
| `xi-observe` | 扶窗远望（谜题 4） | 是 |
| `xi-shiver` | 被冷水送回时的发抖 | 否 |
| `xi-row-boat` | 开场划船（坐姿） | 是 |
| `xi-tie-boat` | 开场系船 | 否 |
| `xi-sit-write` | 结尾坐在灯室写日志 | 是 |
| `xi-stand-gaze` | 结尾久久眺望 | 是 |

- 斗篷、头发的摆动骨骼烘进动画，或留给程序做物理摆动（二选一，在交付说明里写明）。
- 帧率 30 fps，原地动画（in-place），移动速度由程序控制；交付说明里写每个移动 clip 的实际步幅速度。

## 验收标准
- [ ] 上表所有 clip 都存在且名字完全一致。
- [ ] 循环动画首尾无跳帧；`xi-walk` / `xi-jog` 在 1.6 / 3.2 m/s 下无明显滑步（制作人在游戏内观察）。
- [ ] 提灯类动画的风灯挂点在 `hand_r_socket`，灯不穿模。
- [ ] `xi-ignite-lever` 带 `ignite` 动画事件，左手与 022 拉杆握点对齐（在 015 场景中验证），风灯不碰拉杆和点火口。
- [ ] 整体节奏慢、动作克制（制作人对照 style-guide §0 主观验收）。
- [ ] 文件 ≤ 15 MB。
