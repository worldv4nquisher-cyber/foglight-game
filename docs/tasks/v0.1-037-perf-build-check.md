# v0.1-037 性能达标、包体与发布前自检

- **负责人**：程序
- **里程碑**：M6 → M7（交制作人测试前完成；帧率由用户 M8 实机验收）
- **依赖**：023、024、025、026、034、035、036
- **工时估算**：4–6 人日

## 背景
GDD §14（基准 RTX 3060 级、1440p、极致档 60fps；最低 GTX 1650、推荐 RTX 3060；帧时间分配；加载：主菜单 ≤ 15 MB 且 3 秒内出现，首场景包 ≤ 150 MB）、style-guide §8（全部预算与帧时间分配）、`docs/releases/v0.1.md`（验收：桌面 Chrome、Edge、Safari、Firefox）。

## 具体内容
> 按制作人拆单裁定第 8 条（`docs/releases/v0.1.md`「拆单裁定」）：**帧率和帧时间不在本单验收**，由用户在 M8 用实机测并填进报告。本单的自动化只管**包体、加载时间、预算校验**。

1. **预算校验（自动化）**：脚本 `game/scripts/verify-budget.mjs`：在三个场景各取 3 个最差机位（制作人可补充，机位写在 `game/src/config/perf-spots.ts`），三档分别读取 `renderer.info`，断言三角面、draw call 不超过 style-guide §8，加载的贴图尺寸不超过 §8 `textureMaxSize` / `textureMaxSizeEnv`，主角使用的 LOD 符合裁定第 4 条，所有 puzzleCritical 物体为 LOD0。超标则优化（合批、实例化、剔除），**不改 §8 参数**；确需改参数时提给制作人和美术。
2. **加载时间（自动化）**：脚本 `game/scripts/verify-load.mjs`（Playwright + 本地生产构建）：清缓存后测主菜单出现时间、首场景包加载完成时间，结果写入报告。
3. **包体**：`npm run size` 通过（主菜单 ≤ 15 MB、common+s1 ≤ 150 MB）；检查 KTX2/Meshopt 压缩全部生效。
4. **浏览器兼容**：Chrome、Edge、Firefox、Safari（macOS）最新版各通关一次；WebGPU 可用时与 WebGL2 都测（若框架采用 WebGPU 路线）。记录各浏览器的已知差异。
5. **内存**：完整通关一次后显存/内存无持续增长（场景切换释放正常）。
6. 输出性能报告 `docs/releases/v0.1-perf-report.md`：机位截图、各档 draw call、三角面、贴图尺寸、包体大小、加载时间（自动填写）；**「FPS / 1% low / 帧时间」栏留空**，表头注明「由用户 M8 实机填写（基准 RTX 3060 级 1440p 极致档 60fps；最低 GTX 1650 级标准档）」。开发期如用 F3 面板看过帧率，只作自测参考，不写进验收栏。
