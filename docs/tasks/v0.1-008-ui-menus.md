## 背景
GDD §10（UI 流程 mermaid 图 + 界面元素表）。style-guide §6（UI 风格：`#1A2128` 80% 面板、细线描边、琥珀悬停、思源宋体标题/思源黑体正文）。现有 `UIManager`、`PauseMenu`（已有画质切换、帧率、静音、全屏）、`LoadingScreen` 可复用。

## 具体内容
1. 按 GDD §10 mermaid 流程实现全部跳转：启动/加载 → 主菜单 → 新游戏（有存档时覆盖确认）/ 继续 / 设置 / 制作名单；游戏中 Esc 暂停 → 继续 / 设置 / 回到主菜单（提示「将回到最近的场景开头」）；结尾演出 → 章节结束页 → 回到主菜单。
2. **主菜单**：标题字（开发期文字占位，正式图在 030）、按钮：继续（无存档时隐藏）、新游戏、设置、制作名单、版本号。背景是轻量实时场景（灯塔剪影 + 雾墙贴片 + 雨粒子，缓慢推镜），资源算进主菜单包（≤ 15 MB，见 010）；超预算时改用静态插画。存档异常/无法保存的提示（006）显示在这里。
3. **设置界面**（主菜单和暂停共用一个组件）：画质档位 极致/高/标准、鼠标灵敏度、Y 轴反转、主音量/音乐/音效、字幕大小、自动回正、显示帧率、恢复默认。全部读写 006。**不做**点击寻路开关、分辨率缩放滑条、自定义按键（GDD §10/§15）。
4. **暂停菜单**：改造现有 `PauseMenu`：背景模糊 + 暗化；继续 / 设置 / 回到主菜单。现有的全屏切换保留在设置里。
5. **章节结束页**：章节名「第一章 · 归岸」、插画（030，开发期占位）、本章用时、提示使用次数（只陈述不评分）、「未完待续」、回到主菜单。
6. **制作名单**：简单滚动文本（`ui.credits.body`）。
7. **界面文字**：主菜单、暂停、设置、日志、章节结束页、存档提示的全部文字取自 `docs/gdd/text-ch1.md` §9（`ui.*`），不在代码里写死。
7. 所有菜单可用鼠标操作；打开菜单时释放指针锁定，关闭后点击画面重新锁定。
