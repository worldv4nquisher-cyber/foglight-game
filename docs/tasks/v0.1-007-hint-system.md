# v0.1-007 三级提示系统

- **负责人**：程序
- **里程碑**：M4
- **依赖**：004、005
- **工时估算**：1.5–2 人日

## 背景
GDD §7 通用规则（三级提示，玩家按 H 主动打开）、§9（一级 3 分钟、二级再 3 分钟、三级再 4 分钟）、§10（右下角小风灯图标、提示弹窗）。用户已确认保留三级提示。

## 具体内容
1. **谜题区域**：每道谜题配置一个触发体（白盒中由 013–015 放置），玩家首次进入开始计时；谜题解开后该谜题提示失效。离开区域计时暂停、不清零。
2. **解锁节奏**（参数进 `gameplay.ts`）：进入后 180 s 解锁一级 → 再 180 s 解锁二级 → 再 240 s 解锁三级。解锁时右下角出现小风灯图标（淡入，不弹文字、不打断）。
3. **H 弹窗**：显示已解锁层级的提示文案，未解锁层级显示「再等等，四处看看」（`ch1.hint.locked`）。
   - 一级、三级：文本（来自文本表，005）。文本 ID 规则 `ch1.hint.p<n>.l<1-3>`，谜题 5 二、三级按步骤 `ch1.hint.p5.<valve|window_mirror|mid_a|mid_b>.l2/l3`（见 `docs/gdd/text-ch1.md` §7）。谜题 5 步骤 5「点灯」（点火口处于可点灯状态，015）只有一条 `ch1.hint.p5.ignite.l3`：提示已解锁时按 H，不论已解锁到几级都只显示这一条，不高亮、不另计时；该状态退出后回到步骤 4 的提示。支持步骤声明「覆盖文本」即可，不需要为它单独做层级计时。
   - 二级：调用 `highlight()`（004）高亮关键物体 3 秒，同时显示一句文本。
   - **按进度提示**：谜题可声明多个「步骤」，提示内容取当前未完成的步骤（谜题 5 必需：二、三级只针对下一步）。
4. 每次打开一个新层级记一次 `hintsUsed`（006），章节结束页展示。
5. 开发模式：`?hintScale=0.05` 把计时缩短到 5%，方便测试。

## 验收标准
- [ ] 进入测试谜题区域 3 分钟后右下角出现风灯图标，按 H 显示一级提示；6 分钟后二级可用并高亮物体 3 秒；10 分钟后三级可用。
- [ ] 离开区域计时暂停，回来继续计；解开谜题后图标消失、H 不再显示该谜题。
- [ ] 带步骤的测试谜题完成第 1 步后，二、三级提示内容切换为第 2 步。
- [ ] 未解锁时按 H 显示「再等等，四处看看」。
- [ ] `hintsUsed` 计数正确写入存档。
- [ ] `?hintScale=0.05` 生效。
