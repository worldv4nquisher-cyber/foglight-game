# v0.1-036 音频接入与混音

- **负责人**：程序
- **里程碑**：M6
- **依赖**：032、033、034
- **工时估算**：2–3 人日

## 背景
GDD §13（环境音分层、按场景和位置 3D 混合；大部分时间音乐很轻或没有；点亮灯塔是唯一音乐高点）、§10（设置：主音量/音乐/音效）。现有 `AudioSystem`（含缺失时合成音兜底）在此基础上扩展。

## 具体内容
1. 总线：master / music / sfx / ambience，音量读设置（006）。
2. 环境音分层：每个场景配置环境音层（雨、海浪、风、室内钟摆等），按区域触发体淡入淡出（室内外切换 1 s）；3D 定位：海浪、钟、码头吱呀、塔底积水按声源位置衰减；随机单发（雾号每 40–90 s、海鸟每 60–120 s、码头吱呀）。
3. 音乐：场景曲音量很低（-12 dB 相对环境音），场景切换 2 s 交叉淡化；结尾曲由 035 时间轴触发。
4. 交互音效：订阅 004/011/012 事件（敲钟、潮汐、推、镜子咔哒、光束接通、锁、拨盘、阀门、点火…；谜题 5 点火口：`receiver:ready` 起播 `sfx-ignite-ready-loop`、`receiver:lost` 或 `lighthouse:ignited` 时 0.3 s 淡出，`ignition:reminder` 播 `sfx-ignite-ready-pulse`，`xi-ignite-lever` 开始播放时同步起 `sfx-ignite-lever`（音效内部已对齐到第 34 帧），`lighthouse:ignited`（第 34 帧）播 `sfx-ignite`）；脚步按地面材质（GLB 材质名或 `-surface-<类型>` 标记）切换。
5. 音频分组加载随场景（010），主菜单只加载 `mus-menu` 与 UI 音效。
