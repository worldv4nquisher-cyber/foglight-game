# v0.1-005 字幕、阅读界面与日志

- **负责人**：程序
- **里程碑**：M4
- **依赖**：001、004
- **工时估算**：2–3 人日

## 背景
GDD §1 支柱 4（环境讲故事、短字幕）、§3（左键/Space 推进字幕、J 日志）、§9（字幕自动推进每字 0.12 s、最短 2.0 s）、§10（字幕区、阅读界面、日志界面）、§13（无配音）。style-guide §6：字幕底部居中、浅阴影、不加底框，正文用思源黑体。

## 具体内容
1. **文本表**：所有字幕、阅读页、日志条目、提示文案、UI 文本放在 `game/src/content/text/zh-CN.ts`（或 JSON），按 id 引用，代码里不写死中文。文案已定稿为 `docs/gdd/text-ch1.md`，机器可读版 `docs/gdd/text-ch1.json`（`strings` 段为 id → 文本，多页文档为数组；`entries` 段附类型、说话人、触发条件、时长建议，结构见 text-ch1 §11）。用脚本 `game/scripts/import-text.mjs` 把 JSON 转成 `zh-CN.ts`（或运行时直接导入 JSON），ID 原样使用，不改名。说话人颜色、「只一次」记录（`seenLines`，存进存档）按 text-ch1 §0 实现。
2. **字幕系统**：
   - `subtitles.play(lineIds[])` 依次播放；每行显示时长 = max(2.0 s, 字数 × 0.12 s)，到时自动下一行；鼠标左键 / Space 手动推进。
   - 支持说话人前缀（v0.1 只有「汐」的内心独白和父亲的日志朗读，用不同字色区分，颜色用 style-guide §2 正文 `#E4E8EA` / 次要 `#8B959D`）。
   - 字号小/中/大三档，读设置（006）。
   - 演出中字幕与镜头时间轴同步（035 调用 `subtitles.playAt(time)`）。
3. **阅读界面**：`reader.open(docId)` 显示纸张特写（贴图来自 030 `ui-paper-*`，开发期纯色占位）+ 文字版叠加；多页时左右翻页（A/D 或点箭头）；右键 / Tab 关闭；打开时游戏逻辑暂停、背景模糊。首次阅读的文档写入日志。
4. **日志界面（J）**：已拾取的信件/日志条目列表，按章节分组；顶部显示「当前目标」一句话（由谜题进度设置，文案来自文本表）。拾取时左下角提示「日志已更新」2 秒。
5. 已读文档 id 列表交给存档（006）保存。

## 验收标准
- [ ] 一行 10 字的字幕显示 2.0 s，一行 30 字的显示 3.6 s 后自动切换；左键 / Space 可立即推进。
- [ ] 字幕底部居中、无底框、有浅阴影；字号三档切换即时生效。
- [ ] 阅读界面能显示 2 页以上文档并翻页，右键 / Tab 关闭；打开期间角色不能移动。
- [ ] `docs/gdd/text-ch1.json` 全部 ID 可加载；`import-text.mjs` 报告代码中引用但 JSON 中不存在的 ID 为 0。
- [ ] 父亲日志（`ch1.s2.journal.doc`，5 页）可完整翻阅；结尾演出后日志第 6 页出现 `ch1.outro.journal_entry`。
- [ ] 首次阅读的文档出现在 J 日志中，并弹出「日志已更新」；再次阅读不重复添加。
- [ ] 日志顶部的「当前目标」可由代码更新。
- [ ] 代码中除文本表外没有硬编码的剧情中文（`grep` 检查）。
