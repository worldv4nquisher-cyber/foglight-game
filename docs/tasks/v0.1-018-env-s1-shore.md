# v0.1-018 S1 落潮滩场景大件

- **负责人**：美术
- **里程碑**：M6（建议 M4 期间开工；尺寸以本单和 013 白盒为准）
- **依赖**：013（白盒 GLB 用于最终对位；本单列出的尺寸足够先开工）
- **工时估算**：5–7 人日

## 背景
GDD §6 S1（布局、引导：无环境暖光，靠湿铜钟冷高光和构图引导）、§12.2（S1 资源）。style-guide §0（冷、湿、空、静）、§1（场景 3 级明暗、手绘质感）、§5（地形、浅滩按水位设计、近景经得起看）、§8（预算）。高度基准：退潮水面 y = 0.0、涨潮水面 y = 1.6（见 011）。通用交付规范见 `v0.1-index.md`「美术交付通用规范」。

## 具体内容
| 资源 | 文件 | 要求 |
|---|---|---|
| 旧木码头 | `env-pier-wood-ch1.glb` | 长 14 m、宽 2.5 m，桥面 y = 2.2；桩柱有涨潮湿痕；木板方向指向东侧钟台；尽头系船桩 |
| 小船（半淹 / 可系） | `prop-boat-rowboat.glb` | 开场划船用，长约 3 m；另做 `prop-boat-rowboat-sunken.glb` 远处半沉小船（style-guide 示例名） |
| 岸边石台 | `env-shore-ledge-s1.glb` | y = 2.4 钟台 + 送回安全点平台，石砌，湿 |
| 礁石组（模块化） | `env-rock-shore-a.glb` ~ `env-rock-shore-f.glb` | 6 种礁石，可旋转缩放复用；用于礁石小径（顶面 y = 0.3–0.6）和装饰，需 InstancedMesh 友好（单材质） |
| 沙地 / 潮间带地形 | `env-tidal-flat-s1.glb` | 约 40 m × 30 m，沙地 y ≈ 0.1，含推动轨道区域（约 10 m）和石槽锚位 |
| 崖与潮沟 | `env-cliff-s1.glb` | 北侧悬崖、宽 4 m 潮沟（沟底 y = -0.5，沟壁陡直）、近侧崖下石台 y = 1.85 与通往它的石脊、对岸石阶（最下一级 y = 1.85）直到出口 |
| 倒塌渔具棚 | `env-fish-shed-ruin.glb` | 西侧远景，不可进入 |
| 晾网架 | `env-net-rack-a.glb` | 2 种变体，网片用 alpha 测试材质 |
| 远景剪影 | `env-lighthouse-silhouette-far.glb` | 远处其他灯塔剪影（impostor / 贴片），S1–S3 通用；摆放距离 ≤ 250 m（标准档视距，009） |

- 每个大件按通用规范提供 `_lod0/_lod1/_lod2`、`-collider`、光照贴图 UV2。
- 礁石、湿沙要做干/湿两态（粗糙度贴图区分），水位以下部分配合 `uTideLevel` 湿痕线（程序在 025 做材质，美术需在贴图上把潮线以下画成更深的湿色带，或提供湿润遮罩）。
- **不要放任何环境暖光源**（不要暖色窗、篝火、油灯）。
- 场景大件材质总数 ≤ 12 个。

## 交付物
- 上表 GLB：`art/models/env/`、`art/models/props/`
- 贴图：`art/textures/tex-<对象>-albedo|normal|orm.ktx2`（环境贴图 2048，`textureMaxSizeEnv` 极致/高档上限；标准档 1024 由构建脚本生成）
- 源文件：`art/source/env/s1-ebb-shore.blend`

## 验收标准
- [ ] 关键高度与本单一致（码头 2.2、钟台 2.4、礁石小径 0.3–0.6、石台与对岸石阶 1.85、沟底 -0.5，误差 ≤ 5 cm），能与 013 白盒对齐。
- [ ] S1 所有静态大件 LOD0 三角面总和 ≤ 4M、LOD1 ≤ 2.3M、LOD2 ≤ 1M（这是 style-guide §8 `sceneVisibleTris` 极致 6M / 高 3.5M / 标准 1.5M 中留给静态环境的份额，其余给角色、道具、水面、植被）。
- [ ] 每个大件有 `_lod0/_lod1/_lod2`，每级面数约减半；有 `-collider` 简化碰撞网格；有 UV2。
- [ ] 礁石模块单材质，可在程序中用 InstancedMesh 批量摆放。
- [ ] 贴图为 KTX2，普通环境贴图 ≤ 2048。
- [ ] 画面中没有暖色光源；整体冷色低饱和（制作人对照 style-guide §0、§2 主观验收）。
