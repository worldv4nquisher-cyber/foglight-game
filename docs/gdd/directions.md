# 游戏方向候选（供用户选择）

> 状态：草案，待制作人审核、用户选定。选定前不写 GDD 正文。
> 前提：3D 网页游戏（H5，桌面 + 手机浏览器），以后可打包 App/PC；中型项目、长期迭代；Three.js + TypeScript + Vite；不做运营宣传，**全部为单机设计，不依赖在线玩家或社交传播**。

## 总览

| | A 俯视角肉鸽割草 | B 低多边形闯关跑酷 | C 小岛模拟经营 | D 小场景探索解谜 |
|---|---|---|---|---|
| 一局时长 | 10–15 分钟 | 1–3 分钟/关 | 无固定局，挂机+短时操作 | 15–30 分钟/章 |
| 核心乐趣 | 变强、割草爽感、构筑 | 操作、挑战、通关 | 规划、收集、看着家园长大 | 氛围、发现、解开谜题 |
| 手机适配 | 很好（单摇杆） | 好（摇杆+跳） | 很好（点选拖拽） | 中（需要视角操作） |
| 技术风险 | 中（大量怪物性能） | 中（物理手感） | 低 | 中（相机与交互） |
| 内容产出压力 | 低（系统驱动） | 中（关卡手工做） | 中（数值+建筑模型） | 高（每关手工做） |
| 策划推荐度 | ★★★★★ | ★★★★ | ★★★ | ★★ |

## 方向 A：俯视角肉鸽割草（3D 版"吸血鬼幸存者"）

**一句话卖点**：只管走位，自动开火，十分钟从一把小刀变成满屏技能风暴。

**核心玩法循环**
- 局内：移动躲怪 → 自动攻击清怪 → 捡经验宝石 → 升级三选一（新武器/被动/进化）→ 怪物越来越多、出精英和 Boss → 活到时间结束或死亡。
- 局外：局内获得金币 → 解锁新角色、永久属性、新地图 → 开下一局。

**操作方式**
- 键鼠：WASD 移动，攻击自动；鼠标点选升级卡；Esc 暂停。
- 手机：屏幕左半区任意位置按下出现虚拟摇杆；攻击全自动；升级时弹大卡片点选。单手可玩，竖屏/横屏都能支持（v0.1 先只做横屏）。

**美术风格建议**：低多边形 + 卡通平涂（toon 着色），色块鲜明，怪物靠轮廓和颜色区分；技能特效以粒子和发光贴片为主，不用复杂后处理。

**v0.1 可玩范围**
- 1 个角色、1 张无限平铺地图、4 种普通怪 + 1 个 Boss（10 分钟时出现）
- 6 种武器、6 种被动，升级三选一，无进化
- 经验、等级、血量、死亡/胜利结算页
- 无局外成长，无存档（可留本地最高纪录）

**长期迭代空间**：新角色（各自起始武器）、武器进化合成、多地图与环境机关、局外天赋树、成就与图鉴、每日固定种子挑战（本地生成，不需要服务器）、无尽模式。

**风险**
- 技术：同屏 300+ 怪物和大量投射物，需要 InstancedMesh、对象池、简单空间分区碰撞；手机 30fps 是主要指标。
- 美术：怪物需要简单骨骼动画或顶点动画，数量多但每个面数要低；特效工作量中等。
- 设计：数值平衡需要多轮调，但可以用表格驱动。

## 方向 B：低多边形闯关跑酷（单人"糖豆人"式障碍关）

**一句话卖点**：一个圆滚滚的小人，在漂浮的机关岛上跑、跳、扑，摔下去马上重来。

**核心玩法循环**：选关 → 躲开转锤、移动平台、弹板等机关冲向终点 → 按用时和收集物评星 → 解锁下一关和新皮肤。

**操作方式**
- 键鼠：WASD 移动、空格跳、Shift 扑；鼠标拖动转视角。
- 手机：左下虚拟摇杆移动，右下"跳""扑"两个按钮，右半屏滑动转视角；相机默认自动跟随，减少手动调整。

**美术风格建议**：糖果色低多边形，软胶质感，场景是天空背景上的漂浮岛块，模块化拼装。

**v0.1 可玩范围**
- 1 个角色（跑、跳、扑、摔倒动画）
- 6 种机关模块、3 个关卡、存档点、计时与三星评价
- 主菜单、选关、结算页

**长期迭代空间**：按主题出关卡包（冰雪、工厂、糖果）、皮肤收集、时间挑战与本地排行、关卡内收集要素；远期可做关卡编辑器。

**风险**
- 技术：角色手感（加速度、土狼时间、跳跃缓冲）和物理碰撞要反复调，需引入轻量物理库（如 Rapier WASM）。
- 美术：机关模块化，可复用性高，工作量中等。
- 设计：关卡全部手工做，内容产出速度决定更新节奏；难度曲线要控制好，避免手机上太难。

## 方向 C：小岛模拟经营（立体放置建造）

**一句话卖点**：从一块荒岛开始，种田、盖房、开船探索，打造你的立体小世界，离线也在长大。

**核心玩法循环**：采集资源 → 建造生产建筑 → 产出与加工 → 完成订单/升级岛屿 → 解锁新地块、新建筑 → 规划布局提高效率。

**操作方式**
- 键鼠：左键点选/拖拽放置，右键或拖动平移视角，滚轮缩放，Q/E 旋转建筑。
- 手机：单指点选和拖动建筑，双指缩放和旋转视角，底部建造栏点选。全程无需快速反应，很适合手机。

**美术风格建议**：微缩模型 / 移轴感（tilt-shift），暖色低多边形，昼夜光照变化，建筑有升级外观。

**v0.1 可玩范围**
- 一块网格地图，3 种资源（木、石、粮）、6 种建筑、建造/拆除/升级
- 一条订单线和 10 个左右引导任务
- 本地存档（localStorage/IndexedDB）和离线收益

**长期迭代空间**：新岛屿生态、居民与小故事、季节事件、装饰品收集、科技树、航海探索小玩法。

**风险**
- 技术：低，网格建造、存档、经济系统都成熟；需注意大量建筑的合批渲染。
- 美术：建筑种类多且要升级外观，模型数量最大。
- 设计：数值经济平衡和 UI 量大；节奏偏慢，前 10 分钟抓不住人的风险较高。

## 方向 D：小场景探索解谜（第三人称氛围冒险）

**一句话卖点**：在一座座精致的小世界里拨动机关、改变视角，解开谜题，一步步拼出一个安静的故事。

**核心玩法循环**：进入章节场景 → 探索、观察线索 → 操作机关（旋转结构、搬箱子、控制光影）→ 解谜开路 → 剧情片段 → 下一章。

**操作方式**
- 键鼠：WASD 移动，E 交互，鼠标拖动转视角。
- 手机：点击地面寻路移动，点击物体交互，拖动旋转机关和视角。不需要摇杆，节奏慢，操作压力小。

**美术风格建议**：柔和光照、雾效、配色统一的低多边形或手绘贴图，靠灯光和构图出氛围。

**v0.1 可玩范围**
- 1 个章节、3 个小场景、5 道谜题
- 点击寻路、交互系统、简单对话/字幕
- 开头和结尾各一段剧情演出

**长期迭代空间**：按章节更新剧情、新谜题机制、收集品与隐藏结局。

**风险**
- 技术：相机控制、寻路、机关交互状态管理，中等难度。
- 美术：氛围要求最高，每个场景都要精修，灯光烘焙工作量大。
- 设计：谜题和关卡全部手工设计，一次性消耗内容，长期迭代成本最高、可重玩性最低。

---

## 策划建议

首推 **A 俯视角肉鸽割草**：
1. 系统驱动、可重玩性高，同样的内容能玩很多局，最适合长期迭代又不需要运营；
2. 手机单摇杆就能玩，桌面和手机体验接近；
3. v0.1 范围清晰，最快能做出"好不好玩"的判断；
4. 主要技术风险（大量怪物性能）明确，可以在 v0.1 先验证。

备选 **B 闯关跑酷**：上手最直观，但长期更新依赖持续手工做关卡。
