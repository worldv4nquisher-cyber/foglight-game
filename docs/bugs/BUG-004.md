# BUG-004 首次阅读时「日志已更新」提示压在阅读界面下面，读完关掉后提示已经消失，玩家看不到

- 关联：v0.1-005 / acd6d8d·77f0f44（`Reader.open` → `narrative.markRead` → `journal:updated` → `UIManager.toastLeft.show`）
- 严重度：一般（005 验收第 34 条「弹出『日志已更新』」在实际游玩中看不到；日志条目本身写入正常）
- 测试版本：95fc1da 快照 preview，`/?smoke=1&scene=testbed`

## 复现步骤
1. 先执行 `localStorage.clear()`，再打开 `/?smoke=1&scene=testbed`。
2. 走到码头告示（sample-read）前按 E。也可以直接执行 `__game.ui.reader.open('ch1.s1.notice.doc')`。
3. 阅读期间观察左下角，然后按 Tab 或右键关闭阅读界面，再观察左下角。

## 期望
按 text-ch1 的说明（`ch1.common.journal_updated`：拾取或首次阅读任一文档后，在左下角显示 2.0 s），玩家应能看到「日志已更新」。

## 实际
- 提示在阅读界面打开的同一刻弹出，`journal:updated` 只发一次，这一点正确。
- 提示的层级低于阅读界面：`.toast-left` 的 z-index 是 10，`.reader` 的是 22。实测阅读期间每 100 ms 用 `elementFromPoint` 取一次提示中心位置的元素，6 s 内取到的全是 `reader`。截图里看不到这条提示。
- 提示按 UI 帧计时 2 s。正常帧率下，只要读文档超过 2 s，关掉阅读界面时提示早已隐藏。实测关闭后再等 6 帧，`.toast-left` 的文本已经为空。
- 另外，提示的位置（left 18px，bottom 14px）和 HUD 操作提示（`.hud-hint`，left 16px，bottom 14px）重叠。
- 本条全程只在 SwiftShader 下测过。低帧率时 UI 的 dt 被截断，提示实际显示得更久，但始终被阅读界面盖住。

## 修复说明（程序，2026-10-29）
- 原因：`journal:updated` 在 Reader.open 里同步触发，Toast 立刻显示并按 UI 帧倒计时；阅读界面（z 22）盖在提示（z 10）上面，玩家读完关掉时 2 s 早已走完。
- 修复（src/ui/Toast.ts、src/ui/UIManager.ts）：
  - Toast 改为「排队 + 挂起」：`show()` 只排队；`update(dt, blocked)` 在有遮挡时不显示、不计时，遮挡消失后才显示并开始倒计时，所以关掉阅读界面后完整显示 2.0 s（`gameplay.narrative.journalToastSeconds`）。显示途中又被盖住（比如马上按 J 开日志）也暂停计时，露出来后接着走完。
  - 遮挡 = 阅读界面 / 日志 / 暂停菜单 / 主菜单 / 章节结束页 / 场景切换黑场任一打开。
  - 换场景时清掉没显示完的提示，不会带到下一个场景或主菜单。
  - 位置：`.toast-left` 从 bottom 14px 上移到 bottom 48px（left 16px，与操作提示左对齐），在 `.hud-hint` 上方，不再重叠。
- 防回归（smoke 005）：阅读期间 `ui.toastLeft.pending === true` 且 `.toast-left` 隐藏；右键关掉后提示出现、文字为 ch1.common.journal_updated、与 `.hud-hint` 矩形不相交、没有界面盖着、1 s 后仍在、之后消失；再次阅读既不显示也不排队。
- 试玩：`/?smoke=1&scene=testbed`（或 dev `/?scene=testbed`），清 localStorage 后走到父亲日志 / 码头告示按 E，读几秒后右键关闭 → 左下角操作提示上方出现「日志已更新」约 2 s。

## 回归结论（QA batch4，f51491a 快照，2026-10-29 UTC+7）
**已修复。**
- 首次阅读：journal:updated 触发 1 次；阅读界面开着时，提示 hidden=true、pending=true（挂起）。
- 关闭阅读界面后显示「日志已更新」，按游戏时间显示 2.00 s 后消失。软件渲染下墙钟约 8.2 s，因为 UI 帧时间每帧上限 0.25 s。
- 位置：提示框 left 16、top 653、bottom 672；操作提示 top 684。在操作提示上方，不重叠。
- 再读同一份文档：journal:updated 0 次，不再弹。
- 日志（J）开着时（用事件模拟一次 journal:updated）：挂起；关闭后显示。
- 提示显示途中打开暂停：隐藏，剩余时间冻结（2.5 s 后剩余时间不变）；关闭暂停后重新显示，接着走完。
- 黑场 / 主菜单 / 结束页：运行时没有单独测。代码里 `covered` 包含 `flow.transitioning`、`mainMenu.isOpen`、`chapterEnd.isOpen`，切换场景时会清空。
