# BUG-026 结尾父亲镜头：画面上半部偶尔整片叠上一层硬边橙光（疑似灯塔旋转光束）

- 严重度：P3（美术/演出，偶发，约 1–2 s）
- 版本：fe19ab7（snap-fe19ab7，art=1，汐 r4）
- 状态：closed（2026-10-31，QA batch19 ② 回归通过，8453b99 / snap-8453b99；修复 3d9988c 体积灯束，回归单测 ea1f5df）
- 复现：`?smoke=1&debug=1&scene=s3&art=1` 点灯进结尾演出，看父亲手搭头镜头（演出 t≈36–42 s）。QA 用可暂停的后备时钟停在各时间点截图（/workspace/qa-tools/t18-ghost.mjs，batch18 ③）。是否出现取决于光束转到哪，不是每次都有。
- 期望：室内父亲镜头没有这层光；batch17 同镜头 38.4 s 的帧没有。
- 实际：t=38.5 s 这一帧上半画面（窗框、父亲、汐的头发）整片变橙变亮，下沿是一条水平硬边、右侧也有一条竖直硬边；上 300 行平均 RGB (182,153,119)，37 s 为 (133,113,97)、40 s 为 (140,120,103)；下半画面三帧几乎一样（≈(119,89,54)）。汐头顶发色从 ≈(84,50,30) 变成 (196,139,70)。
- 推测原因（未在页面内隐藏光束复核）：src/levels/s3/puzzles.ts buildS3Lamp 的 `lamp-beam-s3`，两只开口 ConeGeometry(3.2, 60) 背对背、加色混合 0xffb25e 不透明度 0.16、DoubleSide、depthWrite false、frustumCulled false、renderOrder 2，按 0.35 rad/s 旋转（两只锥约每 9 s 扫过同一方向一次）。父亲镜头相机在灯室里，光束转到和视线大致同向时锥体从近处横过画面，就会得到这种硬边加色光片，时间和 38.5 s 单帧出现、37 / 40 s 消失吻合。
- 关联：已知问题「镜头 02 结尾光束和圆盘边缘生硬」是同一套光束，但那是另一个镜头；父亲镜头的这一项不在已知列表里，所以单独登记。
- 证据：qa-v0.1-batch18/ghost/ghost-t38.5.png（对比 ghost-t37.png、ghost-t40.png），三帧并排 ghost/bug026-t37-t38.5-t40.jpg。
- 建议：结尾室内镜头里隐藏光束或让它不画进室内相机（layers），或给锥体加距相机淡出 / 软边；也可以在演出开始时把光束角固定到不会扫过室内相机的位置。确认方法：停在 38.5 s，`__s3.scene.getObjectByName('lamp-beam-s3').visible = false` 后重新截图，橙光应该消失（现成脚本 /workspace/qa-tools/t18-wash.mjs 会固定光束角扫 24 个角度，batch18 因 box 内存不足没跑）。

## 关闭（batch19 ②，2026-10-31）
- 版本 8453b99（snap-8453b99，art=1，汐 r5），默认灯束 style='volume'。可暂停后备时钟停在 t=37 / 37.5 / 38 / 38.5 / 39 / 39.5 / 40 s 截图（/workspace/qa-tools/t19-ghost.mjs，TS=… LEGACY=1），每个时间点同帧再切 `setStyle('legacy')` 拍一张对比。证据：docs/bugs/qa-v0.1-batch19/ghost--b026/ghost-t*.png、t19-ghost.json。

- 同帧 legacy：37 s 上半 (165,140,115)、39.5 s (153,132,112)，画面上方出现和 batch18 一样的硬边橙色光片 —— 原因（旧开口圆锥扫过灯室相机）得到确认，新灯束不再出现。
