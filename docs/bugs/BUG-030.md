# BUG-030 桌面端 ramp KTX2 尺寸不是 4 的倍数，汐身体的卡通明暗失效（中）

- 发现：程序 batch22 自查，详见 docs/tasks/ramp-ktx2-0x502-1031.md
- 平台：Windows、Intel Mac、Linux 桌面（转码为 BC7/BC3）。Apple Silicon 和手机正常。
- 复现：桌面 Chrome 打开 ?art=1 进 S1，看汐的身体和头发；控制台会报 0x502。
- 期望：tex-xi-ramp 正常采样，汐有明暗分界和亮面。
- 实际：256×1 的 UASTC 转码后宽高不是 4 的倍数，纹理不完整、采样为黑，身体和头发全程处在冷色暗部，没有分界也没有高光。脸走 SDF，不受影响。参考 shots-031/s1-xi-cuff-side.png。
- 严重度：中（画面观感，桌面是主平台）
- 裁定（制作人 2026-11-01）：采用方案 A，程序在加载时把宽高不是 4 的倍数的 KTX2 转成未压缩 RGBA；ramp 去掉 mip；资源校验加一条「KTX2 宽高必须是 4 的倍数」。M7 之前先修。修完拍修前修后对比图，交美术看，再给用户看。
- 状态：待修
