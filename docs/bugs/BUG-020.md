## 复现步骤
1. `?smoke=1&debug=1&scene=s2&art=1&quality=standard`（默认大气预设，下雨），打开地窖门，走到地窖底层钥匙架前。
2. 或者：`?scene=s3&art=1`，退潮后走进灯塔塔底，看窗口镜 / 楼梯。

## 实际
- 地窖里（上面有房子的地板和梁）能看到斜着的雨丝。此时 `cameraFollow.indoor = true`、`rain.visible = true`，相机在 (-2.29, -0.73, -0.57)。
- 对照：qa-v0.1-batch13/key-hl-fb.png（有雨丝，左上和中间）vs key-hl-fb-norain.png（同一帧位置，把雨的 mesh 隐藏）。除了雨丝，两张图完全一样。
- 灯塔塔底（有屋顶）也一样：qa-v0.1-batch13/mirror-hl-window-lowtide.png，画面里整个都是雨丝。
- 提亮的地窖入口截图 cmp/s2-cellarentry-lm1-boost.jpg 里也能看到。
- 代码：Rain 是跟着相机走的平铺雨块，没有做室内剔除或遮挡。LevelScene 里只有镜头水滴 (`raining && !cameraFollow.indoor`) 和角色湿身 (`xiWetTarget(..., indoorVolumes)`) 用到了室内判定，雨丝 / 溅水本身没有。

## 期望
相机在室内体积里（`cameraFollow.indoor`）时，雨丝不画，或者淡出；至少别让雨丝穿过屋顶 / 地板出现在封闭空间里。窗外能看到雨是对的。
