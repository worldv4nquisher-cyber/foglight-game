# BUG-007 潮汐测试场：从岸台走下礁石路坡，在坡顶接缝处卡住

- **关联单号/commit**：v0.1-011（6a6630a），在 master 4f672e9 快照上复现。代码位置：src/world/tideTestArea.ts 的 `tide-reef-slope-collider` 与 `tide-deck-collider` 接缝。
- **发现**：QA batch5，2026-10-29（UTC+7）。环境：vite preview 构建，headless Chrome，SwiftShader 软件渲染。
- **严重度**：一般（跳一下可以过去；但正常走路被卡住，而且以后正式关卡的「岸台接下坡」可能复用同样的做法）

## 复现步骤
1. 打开 `?smoke=1&debug=1&scene=testbed`，按 Y（或在钟旁按 E）落潮，等水位到 0。
2. 把角色放到岸台 (0, 2.02, 23.0)，相机 yaw=π（朝南）。
3. 按住 W 走 4–5 s。

## 期望
礁石路入口空气墙已经关闭（enabled=false），角色应该从岸台顺着坡（约 21°，低于 maxSlopeDeg 40°）一路走到礁石路上。

## 实际
- 角色停在 z=23.94、y=2.02，一直按着 W 也不动。
- 试了 x=0、0.5、-0.6，结果都一样。后退 0.4 s 再往前走，仍然停在同一位置。
- 从 z=23.3 或 22.5 起步可以走过去。跳一下（W+Space）也能过去。
- 当时附近启用的碰撞体只有 tide-deck-collider（顶面 y=2.0，z≤24）和 tide-reef-slope-collider。坡的厚板旋转后，包围盒顶到 y=2.036、从 z=23.8 开始，也就是坡顶比岸台高出约 3.6 cm，形成一个凸沿。这个高度本该在 stepHeight 0.3 以内被跨过，实际却卡住了，推测与起步相位下的离散步进有关。
- 每次都能复现，前后共 8 次。

## 修复说明

- 修复提交：game/ 仓库 `af76df6`（单独一个提交）。
- 根因：卡住的不是台阶（stepHeight 0.3）这一路，而是 `PhysicsSystem.stepBody` 的**陡坡撤回**。水平移动后用中心射线往下探，如果打到不可走面（法线和竖直方向夹角 > maxSlopeDeg）、并且命中点比起步脚底高 2 cm 以上，就把这一步撤回到起点。测试场的 `slab()` 两端各外伸 0.1 m，坡板旋转后，高端的**端面**（法线和竖直方向夹 69°，陡面）在 z≈23.80–23.91 凸出岸台 3.6 cm。角色中心刚好落进这条约 3 cm 宽的窄带时，射线打中端面，判成陡坡，这一步被撤回。下一步又从同一个位置出发，于是永远卡住。是否落进窄带取决于起步相位（每步位移 2.7 cm），所以从 23.0 起步必卡，从 23.3 / 22.5 起步就能过；跳起来时不走贴地这条分支，所以也能过。
- 改动：
  1. 物理（通用）：陡坡撤回前先判断是不是「矮沿」`isLip`。条件是：陡面高出起步脚底不超过 `lipHeight` 0.06 m，并且沿移动方向往前 `lipLookahead` 0.12 m 处中心射线打到的是可走面、高度也在 0.06 m 以内。满足就当台阶迈过去，不撤回。真陡坡往前看仍然是陡面，照样撤回（「45° 坡走不上去」回归仍然通过）。这样正式关卡里「岸台接下坡」再出现几厘米的凸沿，也不会卡。
  2. 测试场几何：`slab()` 只在低端外伸 0.2 m（埋进地面），高端和岸台顶面齐平。坡顶包围盒 max.y 从 2.036 降到 2.000，礁石坡、北侧坡道都一样。
- 复现点（脚本）：
  - `npm run test:physics` 新增「BUG-007 矮沿」：用旧做法（凸出 3.6 cm）搭一块坡板，从 z 23.0…24.0 共 120 个起步相位以 1.6 m/s 起步走过去，一个都不许卡。
  - `npm run test:tide` 新增「BUG-007 复现点」：用真实的 `buildTideTestArea`、退潮，x 取 0 / 0.5 / −0.6，z 取 23.0…23.99 共 60 个起步相位，走 3 s 必须走到 z > 27；同时断言坡顶不高出岸台。
  - 两条都在修复前失败（物理那条：「卡在接缝：23.000→23.877 …」；潮汐那条：「坡顶 2.036 高出岸台 2.0」），修复后通过。
- 冒烟：`SMOKE_ONLY='011'`（潮汐）、`'002'`、`'013 S1 白盒'` 逐项跑过，都通过。
- 遗留：无。
