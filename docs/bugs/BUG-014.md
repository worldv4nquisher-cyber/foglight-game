## 实际
- 默认视角：候选是 `chart-s2`（提示「E 查看」），按 E 播海图查看，日志 / 风灯都没被选中。各物体焦点的屏幕坐标（NDC）：海图 (−0.14, 0.09)，纸条 (0.01, −0.35)，风灯 (−0.15, −0.27)，日志 (−0.29, −0.37)。
- 第三人称相机围着角色转，左右转镜头时近处物体在屏幕上几乎不动（yaw ±0.3 rad，风灯 NDC x 只从 −0.21 变到 −0.09）。
- 扫描结果：俯仰 −0.3 时 yaw 偏 −0.3…+0.3 全是海图或纸条；俯仰压到最低（−0.6，夹到上限 −0.61）且 yaw 往右偏 +0.2 以上，才选中 `lantern-s2`。换 3 个站位（z 0 / 0.1 / −0.3，朝向 ±0.3）默认俯仰下也都是海图。
- 日志同理：它的焦点离屏幕中心最远（−0.29, −0.37），只靠脚本反复把镜头对准才选中过（§6c、§6d）。
- 选中之后真实按 E 一切正常：拿到风灯，东窗暖光熄灭（opacity 0），`lanternOnDesk` false（截图 qa-v0.1-batch7/s2-lantern-picked.png）。

## 建议（供程序参考）
书桌上物品的选择加优先级（日志 / 风灯高于海图、纸条），或者把海图的焦点 / 可交互角度收窄，或者 inspect 类在同时有 read/pickup 候选时让位；也可以在书桌站位前把选择改成按准星射线命中。

## 修复说明
- **原因**：确认。`pickCandidate()` 只看焦点投影离屏幕中心的距离。书桌站位默认视角（俯仰 −0.16）下各焦点到屏幕中心的 NDC 距离：海图 0.16、风灯 0.31–0.37、纸条 0.35、日志 0.43–0.47、抽屉 0.64，海图离中心最近。第三人称相机绕着角色转，左右转镜头时近处物体在屏幕上几乎不动，所以靠转镜头很难把日志或风灯转到最近的位置。
- **改法**：给交互物加一个可选的「瞄准才选」半径 `aimCone`（`Interactable`，单位是屏幕 NDC 距离）。设了 aimCone 的物体，只有在焦点离屏幕中心 ≤ aimCone 时，才能压过画面里优先级更高的候选；没对准时让位。画面里没有更高优先级的候选时照常参与；不设 aimCone 的物体，选法和以前完全一样。这里沿用已有的 priority：inspect / read = 0，pickup / use 等 = 20。只在 S2 书桌上设了 aimCone（`S2_DESK_AIM`，src/levels/s2/puzzles.ts）：
  - 海图 `chart-s2`：aimCone 0.13。抬头看海图时焦点在 0.02–0.11，能选中；默认视角是 0.15–0.16，让位。
  - 纸条 `xi-note-s2`：aimCone 0.30。默认视角是 0.35，排在日志前面，所以也让位；低头（俯仰 −0.3）时是 0.26–0.27，能选中。
  - 抽屉信纸默认视角下本来就排在日志后面，不设。
  结果：站位默认视角下，第一次选中日志；读完后（风灯在书桌上）选中风灯；抬头看海图仍选海图，低头看纸条仍选纸条。
- **测试**：
  - verify-interaction 新增「BUG-014 aimCone」单测，用书桌缩影场景：海图在 aimCone 外但离屏幕中心比日志近时选日志；把海图移到准星上就选海图；日志不可用时海图照常参与；没设 aimCone 的物体仍按离中心最近选。
  - smoke「v0.1-014 part2」：站位取自 journal 交互点（layout 的 deskInteract），默认俯仰取进场后相机的实际值。结果：默认视角选日志（海图 NDC 0.15 让位）；抬头（yaw +0.3 / 俯仰 0.15，海图 NDC 0.10）选海图；低头（俯仰 −0.3，纸条 NDC 0.27）选纸条；读完日志后默认视角选风灯（NDC 0.30），抬头仍选海图。原有 S2 谜题流程全部通过。
