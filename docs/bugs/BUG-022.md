# BUG-022 阅读器翻页箭头 .reader-arrow 字体回落成 Arial

- 严重度：P3（视觉问题）
- 版本：8ad6b9b（030 UI）
- 状态：closed（batch15）
- 复现：打开一份多页文档（例如父亲日志 journal），查看翻页箭头 ‹ › 的 computed font-family。
- 期望：和其他 UI 一样用 'Foglight Serif'/'Foglight Sans'（以及 Noto/Source Han 回退）。
- 实际：计算出来是 Arial。原因是 `<button class="reader-arrow">` 没有 `font: inherit`，`.reader-nav` 上设的 font-family 没有继承到 button。
- 证据：qa-v0.1-batch14 ② 的 style 探针（scripts/qa-shots-030.mjs QA 副本、t14-ui.mjs）。
- 建议：给 `.reader-arrow`（或全局 button）加 `font: inherit`。
