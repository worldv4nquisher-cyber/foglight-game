# BUG-029 文档 / 注释仍写「极致档反射分辨率 1」，0f42f4a 起实际 0.5（低，文档）

- 版本：0f42f4a（qa snapshot /workspace/qa-tools/snap-0f42f4a）；仓库 HEAD 92fb887 的同两处也未改
- 发现：QA v0.1 batch21 ①（docs/bugs/qa-v0.1-batch21.md ①）
- 现象：0f42f4a 把 ultra 的 `reflections.planar` 从 1 改成 0.5（src/config/quality.ts 第 128 行 `planar: 0.5`），实测 `?quality=ultra` 不加 reflect 参数时 `__s1.reflection.scale = 0.5`、RT 640×360（1280×720 视口），与高档相同。但下面两处还写着极致 1：
