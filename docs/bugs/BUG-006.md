# BUG-006 S3 灯塔在玩家点灯之前就已经亮着（带光束），「点灯」没有可见变化

- 关联：v0.1-010「S3 点灯 → 章节结束页」；f51491a（场景代码来自 e2556b1）；`src/world/Lighthouse.ts:17`（`private _on = true`）、`src/scenes/S3LighthouseScene.ts:68–71`（`lightTheLamp` 里 `if (!this.lighthouse.on) this.lighthouse.toggle()`）
- 严重度：一般（流程能走完，结束页也正常出现；但本章的核心动作「点亮灯塔」在画面上看不出来，和 GDD 不一致。场景是白盒占位，要不要现在修请制作人定）
- 测试版本：f51491a 快照，无头 Chrome（SwiftShader）

## 复现步骤
1. 打开 `/?smoke=1&debug=1&scene=s3`，或者正常流程 S1 → S2 → S3。
2. 进入 S3「初望灯塔」后，不做任何操作，看灯塔。
3. 走到灯塔底下（大约 0,-2.4，面朝灯塔），出现「E 操作」后按 E。

## 期望
GDD §4 / §5.5：初望灯塔「本章点亮」；§8：S3「暴雨前的铅色天空，点亮后雨里的光束」。也就是说，进 S3 时灯塔应该是暗的，按 E 点灯后灯和光束亮起来，1.5 s 后进结束页。

## 实际
- 一进 S3，灯塔已经亮着，光束也在转（`__game.scenes.current.lighthouse.on === true`）。
- 按 E 后只有一声提示音。因为灯已经是开的，`lightTheLamp` 不会再切换，画面没有任何变化，1.5 s 后进结束页。
- 原因：Lighthouse 的 `_on` 默认是 `true`，S3LighthouseScene 进场时没有把它关掉。
- 附带：提示用的是通用的「E 操作」（`ui.prompt.operate`），不是「点灯」一类的专用文案。仅供参考，不算本缺陷的一部分。

## 修复说明

- 原因：占位 `Lighthouse` 的 `_on` 默认 `true`，`S3LighthouseScene` 进场时没有关；而且熄灭状态下点光源仍留 3% 暖光、灯室 0.2 自发光。
- 修复（`src/world/Lighthouse.ts`、`src/scenes/S3LighthouseScene.ts`）：
  - `new Lighthouse({ lit })`：可以以熄灭状态创建；新增 `setOn(on)`（`toggle()` 走它）。熄灭 = 光束隐藏、点光源关闭（intensity 0 且 visible=false）、灯室不自发光 —— 不留任何暖光（符合「环境不出暖光」）。
  - S3 初望灯塔用 `{ lit: false }` 创建：进场是暗的；在塔下按 E 点灯 → `setOn(true)` 灯室 + 点光源 + 旋转光束亮起 → 1.5 s 后结束页。
  - S1 / 菜单 / 沙盒远景灯塔不变（默认点亮）。
- 回归：smoke「v0.1-010」S3 一段新增断言：进 S3 时 `lighthouseOn === false`，点灯后为 `true`，再进结束页。
- 试玩：`?scene=s3`（开发服务器或加 `&debug=1`）→ 进场灯塔暗、无光束 → 走到塔下（约 0,-2.4，面朝灯塔）按 E → 灯和光束亮起 → 1.5 s 后结束页。
- 后续：015 用 020 正式灯塔模型替换占位时保持同样的接口（初始熄灭 + `setOn`）。提示文案仍是通用「E 操作」（QA 附带项，未改；要专用「点灯」文案需策划在 text-ch1 补 ID）。
