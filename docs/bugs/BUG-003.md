# BUG-003 生产构建的 CSS 丢了无前缀的 backdrop-filter，暂停菜单、阅读界面和日志的背景模糊在 Chrome 里失效

- 关联：v0.1-008 / 95fc1da（暂停菜单遮罩）；v0.1-005（`.reader` / `.journal` 遮罩）；构建配置 vite 8 的 CSS 压缩
- 严重度：一般（纯视觉问题，功能不受影响；影响 style-guide §6 的面板观感，preview 和正式包都会出现）
- 测试版本：95fc1da 快照 /workspace/qa-tools/snap-95fc1da/game，`npm run build` 后用 `vite preview` 打开，浏览器为 headless Chrome（SwiftShader）

## 复现步骤
1. 在快照里执行 `npm run build`，然后查看 `dist/static/index-*.css`：
   `grep -o "[^}]*backdrop-filter[^}]*}" dist/static/*.css`
2. 用 preview 打开 `/?smoke=1`，点「新游戏」，按 Esc 打开暂停菜单，在控制台执行 `getComputedStyle(document.querySelector('.pause-menu')).backdropFilter`。
3. 打开 `/?smoke=1&scene=testbed`，执行 `__game.ui.reader.open('ch1.s1.notice.doc')` 后，同样读 `.reader` 的计算样式。

## 期望
`src/ui/styles.css` 第 308–309 行（`.pause-menu`）和第 586–587 行（`.reader, .journal`）同时写了 `backdrop-filter` 和 `-webkit-backdrop-filter`。构建产物应保留无前缀的 `backdrop-filter`，Chrome 和 Firefox 里背景模糊才会生效。

## 实际
- 构建产物里两条规则都只剩带前缀的写法：`.pause-menu{-webkit-backdrop-filter:blur(6px);…}` 和 `.reader,.journal{-webkit-backdrop-filter:blur(6px)brightness(.6);…}`，无前缀的 `backdrop-filter` 被压缩时删掉了。
- Chrome 不认 `-webkit-backdrop-filter`。preview 中三处的计算样式都是 `none`，`.pause-menu` 和 `.reader` 实测为 none，`.journal` 用的是同一条规则。`CSS.supports('backdrop-filter','blur(6px)')` 返回 true，可见是 CSS 规则丢失，不是浏览器不支持。
- 截图里阅读界面和暂停菜单后面的场景是清晰的，没有模糊。
- 推测原因：vite 8 默认用 lightningcss 压缩 CSS，按 `build.target` 合并了带前缀和不带前缀的声明。这只是推测，没有验证。
- 未能对照的部分：本想用 dev 服务器做对比，但它在 240 s 内没能加载出测试场景（当时机器负载很高），所以 dev 模式下是否正常没有实测。从源码看，dev 模式下原样加载的 styles.css 应该是正常的，这一点属于推断。

## 修复说明（程序，2026-10-29）
- 根因（已验证）：不是 build.target 合并，而是 lightningcss 对 backdrop-filter 的前缀处理——同一条规则里**先写无前缀、后写 `-webkit-`** 时，它把两者当作同一属性的不同前缀版本，后写的覆盖先写的，无前缀版本被删。直接调用 node_modules/lightningcss 复现：
  - `a{backdrop-filter:blur(6px);-webkit-backdrop-filter:blur(6px)}` → `a{-webkit-backdrop-filter:blur(6px)}`（给不给 targets 都一样）
  - 只写 `a{backdrop-filter:blur(6px)}` + es2020 targets → `a{-webkit-backdrop-filter:blur(6px);backdrop-filter:blur(6px)}`（自动补前缀，正确）
  - mask-image 同样顺序不受影响，所以只有 backdrop-filter 中招。
- 修复：src/ui/styles.css 删掉手写的 `-webkit-backdrop-filter`（.pause-menu、.reader/.journal）和多余的 `-webkit-mask-image`，前缀交给 lightningcss 按 build.target 自动补。产物现在是 `-webkit-backdrop-filter:…;backdrop-filter:…`，Chrome / Firefox / Safari 都生效。
- 防回归：
  - 新增 `npm run css`（scripts/check-css.mjs），接在 `npm run check` 的 build / size 之后：源码不许手写 backdrop-filter / mask 前缀；源码中带 backdrop-filter / mask-image / user-select 的每条规则，产物同一选择器下必须保留无前缀写法，backdrop-filter 还必须带 -webkit- 版本。用修复前的 dist 跑会报「产物 .pause-menu 丢了无前缀 backdrop-filter」。
  - smoke 008 读暂停遮罩 `getComputedStyle(.pause-menu).backdropFilter === 'blur(6px)'`，005 读阅读界面 `blur(6px) brightness(0.6)`。
- 回归建议：preview 打开 `/?smoke=1`，新游戏 → Esc，背景应模糊；`/?smoke=1&scene=testbed` 走到码头告示按 E，纸后场景应模糊变暗。
