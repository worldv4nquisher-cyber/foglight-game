## 观察（不算缺陷，供参考）

1. 机关中按 Esc 暂停，点「继续」后指针没有锁定。这时第一次右键只会重新锁定指针，不会退出机关（Tab 正常）。这符合 001 的设计（「继续后再次点击画面重新锁定」，KeyboardMouseInput 的注释也这样写），但玩家可能会觉得「右键没反应」。是否改成「锁定的同时也执行这一下的 action」，由策划决定。
2. 测试期间 game/ 工作区有程序员**未提交的改动**（quality.ts、Game.ts、PauseMenu.ts、TestbedScene.ts 等，以及新文件 QualityBenchmark.ts、vram.ts），另外 HEAD 上多了 6bb5d37（tools: verify-lod）。用 dev 服务器跑当时的工作区时，看到过两个运行时异常，都只出现在未提交代码里，**92e044f 快照里没有**：
   - `PauseMenu.refresh`：`QUALITY_PRESETS[q.auto]` 为 undefined（窗口失焦 → 暂停 → 打开菜单时）
   - `TestbedScene.fixedUpdate`：读取 undefined 的 `body`，每帧都会报
   所以本次验收全部改用 92e044f 的冻结快照。这批改动随后（06:50 UTC+7）提交为 **c73645f v0.1-009**。c73645f 里这两处是否还在**没有验证**（本轮复查脚本被环境的安全检查拦下，没跑成），建议下一批验收 009 时重点复查。
