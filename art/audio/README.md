# art/audio — v0.1-032 音效与环境音

素材来源 / 授权见仓库根 **[audio/CREDITS.md](../../audio/CREDITS.md)**：全部为程序合成（Python numpy / scipy + ffmpeg libvorbis 编码），自有作品，**未使用任何录音样本或外部素材**（032 音效 / 环境音）。v0.1-033 配乐见 **[music/README.md](music/README.md)**（用到 CC0 采样，逐条见 docs/audio-credits.md）。
生成：`python3 art/source/audio/gen_audio.py [--only=名字,…]`（固定种子，可复现）；本 README 由 `art/source/audio/gen_readme.py` 从 `audio-report.json` 生成，数字均为**解码后的 ogg 实测**。

- 格式：Ogg Vorbis，44.1 kHz；环境音立体声 112 kbps（单发环境音 96 kbps），sfx 单声道 q4（~64 kbps）。共 79 个文件，7.66 MB（上限 25 MB）。
- 路径：`art/audio/sfx/`、`art/audio/ambience/`；`art/audio/music/` 是 033 配乐（另见 music/README.md）。manifest URL：`assets/art/audio/<sfx|ambience|music>/<名字>.ogg`。
- 响度：环境音 ≈ −24 LUFS，sfx ≈ −18 LUFS，真峰值 ≤ −1 dBTP。**短促的瞬态音**（脚步、咔嗒、UI 等 < 1 s）受 −1 dBTP 上限约束（已用 ≤ 8 dB 的前瞻限幅），积分响度比目标低 2–8 LU，属正常；听感上与其他 sfx 相当。刻意更轻的：ready-loop −28、ready-pulse / bell-wind / UI −24、beam-hum −26、海鸥 −28、钟摆 −28（其余见表）。
- 循环：所有循环都在**环形时间轴上构造**（环形滤波 / 卷积混响、事件绕回、音调取整周期），首尾天然相接；文件起点已旋到最安静的 50 ms。循环点 = 整个文件（0 → 样本总数），程序直接 `loop = true` 即可，无需 loopStart/End。接缝检查（解码后）：接缝二阶差分台阶 ≤ 近邻 0.1 s 最大台阶 +3 dB，或比 RMS 低 ≥ 24 dB；另查编码前源信号。表里「源」= 编码前接缝台阶。剩余的是 Vorbis 收尾的编码误差量级（−50 dBFS 级），不可闻。

## 关键时间点（与动画帧对齐）

- **点火（017 `xi-ignite-lever`，30 fps）**：`sfx-ignite-lever` 与动画第 0 帧同时播 — 文件 0.500 s = f15 上手、0.733–1.133 s = f22–34 拉动、**1.133 s = f34 到底咔嗒**；`sfx-ignite` 在 **f34** 另行 `sfx:play`（文件 0 s 即打火），同帧 `lighthouse:ignited` 停 `sfx-ignite-ready-loop`。
- **ready**：`receiver:ready` → `sfx:loop sfx-ignite-ready-loop`（淡入 `igniterHumFadeInSec`）；20 s 未操作 → `sfx-ignite-ready-pulse`（膨胀峰在 0.8 s）；`receiver:lost` / `lighthouse:ignited` 停。两者同调（110 Hz）。
- **钟锤**：`TideBell` 在 |相对角| 上升沿到达 `clapperHitRad`（0.0537 rad）那一帧播 `sfx-tide-bell-clapper`，文件 0 s 即接触瞬态（0.112 s 一下轻回弹）；主钟声 `sfx-tide-bell-ring` 击打在文件 5 ms 处。
