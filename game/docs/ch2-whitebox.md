# 裂湾村 · 开发阅览

只供开发审阅，不写存档，不从第一章的菜单、关卡或结尾进入。GitHub Pages 的生产构建不包含裂湾村。

在 `game/` 运行 `npm run dev`，然后打开：

| 场景 | 可走入口 | 固定镜头 `view` |
|---|---|---|
| 峡口与船骸 | `/?quality=low&ch2-whitebox=s1` | `overview` / `dock` / `market` |
| 镜巷 | `/?quality=low&ch2-whitebox=s2` | `overview` / `plaza` |
| 崖顶与礁柱灯塔 | `/?quality=low&ch2-whitebox=s3` | `overview` / `cable` |

固定镜头在入口 URL 后追加相应的 `&view=overview` 等参数。去掉 `view` 即可步行。三处采用同一世界坐标，共用峡谷、北鲱号和塔礁。

S1 试玩：码头按 E 看潮，开始退潮后到闸杆封闸。等外水落稳，登浮渡船到卸货码头。扣上配重后操纵吊臂，起吊、回转、下放鱼箱；从鱼市旁上楼，踩鱼箱登甲板。H 看线索、J 看手记；操作机关时按 Tab 返回、R 重置。鱼市门口的通告和去向黑板可读。登甲板后可按 E 进入镜巷。

S2 试玩：从甲板的告示了解雾天传光的顺序。两岸居民用檐镜把礁柱灯塔的光接力送到峡尾雾号。靠近黄铜调节柄按 E，Q / E 转镜，观察光束落点；Tab 返回，H 看线索，R 重置整条镜链。熏房的镜子固定不动。雾号接到光后，从西岸折返梯上崖，在出口按 E 进入 S3。

S3 靠近缆车站按 E 跨到礁柱，再走塔内螺旋坡道上灯室。缆车配重和半盏灯仍是白盒占位。
