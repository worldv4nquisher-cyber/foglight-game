# 雾灯 · 游戏工程

游戏代码在本目录。请先阅读仓库根目录的 [README.md](../README.md)。

开发与构建在本目录执行：

```bash
npm ci
npm run dev      # http://localhost:5173
npm run build
npm run preview  # http://localhost:4173
```

运行时美术位于同级的 [`../art`](../art)（Vite 会把 `/assets/art/` 映射过去）。内部工程说明已移至 [docs/engineering.md](docs/engineering.md)。
